# Windows 1.2.19 · 失败海报加载退避

近期加载失败的封面不再随页面重绘反复请求，避免坏图持续占用封面加载队列。失败后等待 30 秒才允许再次尝试，连续失败逐步延长，最长 5 分钟；成功后清除失败状态并沿用正常磁盘缓存。

失败状态仅保留在内存，最多 200 条；不同网站的 Referer 上下文分别处理，避免一个站点的防盗链失败阻塞另一站点。保留原有并发限制、请求去重及备用 Referer 尝试。不删除用户数据或已有海报。

验证：64 项回归测试，覆盖并发失败去重、重复重绘不重试、退避与恢复、上下文隔离和内存上限；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.19.exe，原 Data 和旧版 EXE 保留。
