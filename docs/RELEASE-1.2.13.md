# Windows 1.2.13 · 大目录转存核验提速

115 分享转存后的目录核验改用文件身份索引，避免每个源文件反复遍历整个目标目录。文件名、文件类型、大小和可用的校验值仍需匹配，每个目标项目只允许匹配一次；同名同大小项目优先匹配相同校验值，减少误判。

新增 12000 个逆序文件的规模回归：12 次目录读取完成核验，目标文件名称读取量保持线性增长。覆盖同名重复、校验值缺失或不符、大小不符及停止场景。未增加转存 POST，也不重试历史记录。

验证：58 项回归测试、隔离数据 Electron 界面检查和打包文件校验。未使用真实账号转存，未修改用户 Data。只发布 Windows x64 完整 EXE。

请从系统托盘退出旧版，再运行 CloudSave-Windows-1.2.13.exe。原 Data 和旧版 EXE 保留。
