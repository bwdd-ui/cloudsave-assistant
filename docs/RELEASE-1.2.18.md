# Windows 1.2.18 · 减少资源库首次加载的重复刷新

观影、BT影视、聚影和七味首次读取资源列表成功后，原先还会发送缓存更新事件，让已在等待结果的页面额外再读取一次。本版由当前请求直接完成显示，取消这次多余通知和页面重读。

已有旧缓存会立即显示；后台更新成功后仍发送一次通知，让页面显示新内容。请求去重、失败保留缓存及失败退避规则保持不变。不会清空原缓存或改变监控查询。

验证：63 项回归测试，覆盖四个资源库首次加载不重复刷新、缓存命中及后台更新通知；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存。只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.18.exe，原 Data 和旧版 EXE 保留。
