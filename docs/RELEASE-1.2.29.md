# Windows 1.2.29 · 海报下载内存保护

海报下载改为流式读取，实际读取超过 5 MiB 时立即停止，不再等待整张异常图片读入内存。即使网站未声明大小或声明值偏小，也执行相同限制。

错误 HTTP 响应、非图片及声明超限的响应会主动关闭读取，减少连接占用。正常图片、缓存、并发限制及失败退避规则保留。

验证：74 项回归测试，新增真实 ReadableStream 测试，覆盖未声明及伪报大小、5 MiB 边界、空响应、流中断、取消失败及后续下载恢复；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.29.exe，原 Data 和旧版 EXE 保留。
