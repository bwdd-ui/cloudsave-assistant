# Windows 1.2.31 · 同步计时边界保护

修复 115 云下载自动同步的计时边界：系统时间回拨或缓存时间异常导致等待时间超过 Node.js 计时上限时，旧版可能把超长等待压缩成约 1 毫秒，反复唤醒调度。

单次等待现在限制在安全范围，超长等待到点后重新计算剩余时间，不提前发起同步。非有限的异常时间按最少 1 秒等待处理，关闭及旧计划失效保护继续生效。正常同步间隔、用户配置和缓存数据保留。

验证：76 项回归测试，新增模拟时钟测试，覆盖多段超长等待、异常时间、过期时间和关闭后的旧计时器；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.31.exe，原 Data 和旧版 EXE 保留。
