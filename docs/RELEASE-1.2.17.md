# Windows 1.2.17 · 修复未提交记录卡在处理中

修复分享监控在准备记录持久化期间停止任务，或保存准备记录失败时，尚未发出的转存请求可能留下“处理中”记录的问题。本版把准备记录保存、停止检查及提交纳入统一结果处理；明确未提交的记录标记为失败，不再永久阻塞该链接。

重启后，已确认未提交的记录仍可按任务筛选规则重试；已经提交但结果不明确的记录继续保留待核对，禁止自动重复提交。不会批量修改历史处理中记录，因为旧记录无法确认是否已经提交。

验证：62 项回归测试，覆盖准备保存中停止、准备保存失败、提交后停止以及从持久化记录重启。隔离 Data 的 Electron 界面检查和打包校验通过，未使用真实账号转存。只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.17.exe，原 Data 和旧版 EXE 保留。
