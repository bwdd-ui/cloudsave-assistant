# Windows 1.2.67：离线记录日期筛选

## 新增功能

- 离线任务的“提交记录”增加开始日期和结束日期，可按本地日期范围检索全部已加载记录，并与来源、状态、关键词条件组合使用。
- 复制链接、保存筛选链接 TXT、复制筛选表格和导出当前筛选 Excel 均使用同一组日期条件，跨越当前分页汇总所有匹配结果。
- “清空筛选”会同时清除关键词及日期。日期范围反向或记录时间缺失时，不会错误放行记录。

## 使用入口

打开“离线任务”→“提交记录”，设置“开始日期”和/或“结束日期”。导出当前筛选仍只导出符合页面筛选的记录；“导出全部历史为 Excel”保持原有全量行为。
