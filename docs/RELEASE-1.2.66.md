# Windows 1.2.66 · 保存当前筛选的历史链接

- 新增：离线任务 → 提交记录新增“保存筛选链接TXT”，按当前来源、状态、关键词及115云下载状态筛选，把全部匹配页的去重磁力、电驴或分享链接保存为 UTF-8 文本文件，方便归档或交给批量离线功能使用。
- 优化：保存按钮显示可导出的匹配链接数量；没有可用链接时禁用。使用系统保存对话框选择路径，不会自动提交离线或转存分享。
- 修复：保存前对链接类型、单条及总量、换行进行校验，确保每行一条链接；添加 UTF-8 BOM 方便 Windows 记事本打开中文分享链接，日志故障也不会把已完成的文件保存误报为失败。

使用入口：左侧“离线任务” → “提交记录” → 设置来源/状态或输入关键词 → “保存筛选链接TXT（数量）”。文件包含所有匹配结果，不受当前分页影响；需要筛选云下载记录时可点击状态计数后再保存。

验证：111 项回归测试；新增覆盖去重、UTF-8 BOM/CRLF 格式、非法协议/换行/超长输入和筛选全页 UI 行为。Electron 隔离界面检查使用临时 Data、禁用网络、不登录真实账号、不执行离线或分享转存。

使用新 EXE 前可从托盘退出旧版本；将程序放在原程序目录可沿用已有 Data。旧版本和用户数据保留。
