# Windows 1.2.51 · 资源浏览缓存容错

修复网站资源列表已成功读取，但本地浏览缓存保存失败时，列表读取也被判定为失败的问题。现在缓存写入异常不会丢弃已读取的列表，后台刷新仍通知界面更新，已经更新的内存缓存仍可复用。

缓存写入失败记录为“资源库已读取，本地浏览缓存暂未保存”，不再混同网站读取失败或触发网站失败退避。后续刷新写入恢复时，继续保存最新列表。真正的网站读取失败仍保留原有报错、旧缓存和退避机制；不改变自动监控的新鲜数据查询。

验证：96 项回归测试，新增真实 CatalogCache 写入失败的首次加载、后台更新、内存复用、通知、日志失败隔离、后续写入恢复，以及网站错误退避测试。旧版问题已复现。隔离 Data 的 Electron 界面检查、打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.51.exe，原 Data 和旧版 EXE 保留。
