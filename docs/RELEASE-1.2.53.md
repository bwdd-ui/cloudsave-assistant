# Windows 1.2.53 · 聚影读取停止保护

修复聚影请求等待登录状态期间，服务已经关闭或停止，但登录状态返回后仍继续发起网站请求的问题。现在登录状态读取完成后、发送网络请求之前，再次检查停止状态。

已关闭的排队请求在轮到执行时直接停止，不再进入请求间隔等待或读取登录状态。取消的合并读取会释放记录，恢复运行后可正常重新读取。保留原有网站冷静期、请求间隔与队列顺序；不声称已发送的网络请求会被此改动撤回。

验证：98 项回归测试，新增等待登录期间关闭/停止不发送请求、关闭后不等待或读取登录、取消后释放合并请求及恢复读取测试。旧版停止后仍发送的问题已复现。隔离 Data 的 Electron 界面检查、打包代码核对和源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.53.exe，原 Data 和旧版 EXE 保留。
