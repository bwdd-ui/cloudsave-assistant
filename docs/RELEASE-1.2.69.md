# Windows 1.2.69 · 重试前校验保存目录

## 新增功能

- 本版本没有新增独立功能。

## 优化

- 离线任务 → 提交记录 → 重试失败磁力：执行重试前明确检查当前默认目录是否需要重新选择。若账号已切换或目录选择已失效，会提示先去“账号与设置”重新读取并设置有效目录，并且不调用批量提交。

## 修复

- 修复了重试历史中的失败磁力时，界面仍可能把已失效目录显示成目标目录的问题。现在目录标记为需要重新选择时会在发送前拦截，减少误导与误提交风险；已配置的有效目录、历史记录及用户数据保持不变。

## 使用入口

离线任务 → 提交记录 → 筛选明确失败记录 → 点击“重试失败磁力”。若默认目录已失效，先前往账号与设置重新读取文件夹并选择目标目录，再返回重试。

## 验证

`npm test` 全量模拟回归（111/111 测试文件通过）及桌面 Electron UI smoke。新增回归覆盖失效目录时零批量提交调用；未使用真实账号或触发真实转存。
