# 云存助手 Windows 1.2.6 · 观影会话保存稳定性

- 修复观影登录窗口在保存登录状态期间关闭时，读取已销毁窗口可能抛出 Object has been destroyed 的问题。
- 窗口关闭或读取浏览器身份失败时，使用持久浏览器会话的身份，继续保存 Cookie 与已读取的网站状态，并刷新到磁盘。
- 原登录窗口操作、现有会话优先和仅补充缺失网站存储的行为保留。网站会话过期或重新要求验证时仍可能需要重新验证。

新增关闭窗口、读取网站状态期间关闭、窗口身份读取异常的隔离测试，同时将已有观影会话恢复测试纳入主回归。50组回归通过。未使用真实账户测试登录、离线或网盘转存。只发布Windows x64完整EXE，其他平台版本不更新、不上传。

退出旧程序及托盘实例后，在原Data旁运行 CloudSave-Windows-1.2.6.exe；原数据和旧程序保留。
