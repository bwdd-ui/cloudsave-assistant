# Windows 1.2.42 · 观影会话部分恢复

修复观影 Cookie 备份中一条记录损坏或单条恢复失败时，后续有效 Cookie 被一起跳过的问题。恢复现在逐条处理，继续恢复有效记录，并保留浏览器中已续期的新会话。

异常备份会汇总一条警告，不输出 Cookie 内容；备份或日志异常不会阻止后续保存当前浏览器会话。正常域隔离和加密保存规则保留。

验证：87 项回归测试，新增损坏条目、单条拒绝、有效记录继续恢复、会话保留及日志异常测试；隔离 Data 的 Electron 界面和子路径会话检查、打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.42.exe，原 Data 和旧版 EXE 保留。
