# Windows 1.2.41 · 海报磁盘缓存保护

海报缓存现在先检查文件类型和大小，再读取内容。异常膨胀或非普通文件的缓存会跳过，避免整份读入内存后才发现超限。

跳过异常缓存后仍按原下载规则获取封面并尝试修复缓存；正常封面缓存继续复用，磁盘写入失败也不会丢弃已下载封面。

验证：86 项回归测试，新增超限稀疏缓存文件测试，确认读取前拦截、下载修复、修复后复用及非文件路径处理；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.41.exe，原 Data 和旧版 EXE 保留。
