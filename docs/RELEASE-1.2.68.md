# Windows 1.2.68 · 筛选后重试失败磁力

## 新增功能

- 离线任务 → 提交记录中增加“重试失败磁力”。按钮只处理当前来源、状态、关键词和日期筛选结果里的明确 `failed` 磁力/电驴链接，并在提交前显示当前默认目录及数量、要求确认。
- 只有用户点击并确认后才会提交；提交待确认、保存目录异常、网盘分享链接不会自动重试，避免对结果不确定的任务重复提交。
- 重试沿用现有批量提交和离线任务去重、大小限制、默认目录校验，并在完成后刷新历史。

## 优化

- 重试前先锁定按钮直到确认或取消，防止连续点击发起多批提交。

## 修复

- 本版本没有独立缺陷修复项。

## 使用入口

离线任务 → 提交记录 → 按来源/状态/关键词/日期筛选 → 点击“重试失败磁力（数量）” → 核对目标目录后确认。

## 验证

`npm test` 全量模拟回归，以及桌面 Electron UI smoke。模拟测试确认跨筛选范围统计、仅明确失败的磁力可重试，待确认/目录异常/分享链接排除，提交期间按钮锁定；未使用真实账号或触发真实转存。
