# Windows 1.2.12 · 运行版本提示与重复启动保护

旧版留在系统托盘时，双击新版会唤回旧窗口，容易误以为已经升级。本版在重复启动时明确提示本次程序未启动、刚打开的版本号以及从托盘退出旧程序的方法；不会中断已有监控任务。

页面顶部始终显示当前实际运行的程序版本。单实例检查提前至缓存写入器和资源服务初始化之前，避免重复启动进程初始化额外的后台写入器。保留原有 Data 路径和单实例锁范围。

验证：57 项回归测试、隔离 Data 的 Electron 实际界面检查及打包文件校验。未使用真实账号转存。仅发布 Windows x64 完整 EXE，用户 Data 不包含在发布资产中。

请先在系统托盘右键云存助手选择“退出程序”，再运行 CloudSave-Windows-1.2.12.exe。复制新文件不会自动替换正在运行的旧进程。
