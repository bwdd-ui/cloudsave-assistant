# Windows 1.2.33 · 后台刷新回调保护

修复资源库后台刷新中，界面通知或日志回调异常可能影响刷新结果的问题。界面通知失败不再把已成功读取的资源误记为网站读取失败；错误日志回调失败也不再导致后台刷新 Promise 拒绝。

保留本地缓存、真实读取失败的退避间隔和恢复重试；首次加载的真实读取错误仍会反馈到界面。

验证：78 项回归测试，新增通知与日志异常测试，覆盖成功缓存保留、失败退避、恢复刷新、待处理请求清理和首次加载错误；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.33.exe，原 Data 和旧版 EXE 保留。
