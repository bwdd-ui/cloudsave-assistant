# Windows 1.2.65 · 复制筛选提交记录表格

- 新增：离线任务 → 提交记录提供“复制筛选记录表格”，可将当前来源、状态、关键词和115任务视图下全部匹配记录以制表符分隔表格复制，便于直接粘贴到 Excel/WPS；按钮显示匹配数量，不受当前列表分页限制。
- 优化：复制表格使用与完整历史相同的时间、来源、状态、标题、目录、链接和反馈列；云端独有任务保留“115云下载”来源和对应状态。
- 修复：复制前清除单元格内的制表符和换行，防止记录错列；对以公式符号开头的文本做安全转义，避免粘贴表格时被电子表格当作公式执行。

使用入口：左侧“离线任务” → “提交记录” → 选择来源/状态、输入关键词或点击115云下载状态 → 点击“复制筛选记录表格（数量）”。随后可粘贴到 Excel、WPS 或其他表格软件。只复制当前匹配项，页面其他记录不会一并复制。

验证：110项回归测试；纯逻辑测试覆盖来源/状态标签、云端独有任务、制表符/换行清理及公式转义；Electron 隔离界面测试覆盖当前筛选和全页复制，未访问真实网站或执行真实离线/转存，系统剪贴板未被修改。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.65.exe；放在原程序目录即可沿用原有 Data。旧版 EXE 与用户数据保留。
