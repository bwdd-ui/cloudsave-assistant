# Windows 1.2.23 · 云下载同步计划竞态修复

115 云下载同步定时器增加计划代次校验。修改同步计划或取消定时后，旧回调不再启动同步；旧同步结束时，也不会重新安排定时器并覆盖较新的计划。

定时触发到异步执行之间再次检查停止状态，避免关闭程序或取消计划后仍从这个间隙启动同步。已开始的同步保留原收尾流程，不强行丢弃缓存。

验证：68 项回归测试，覆盖过期定时器、回调后的异步间隙停止、运行中修改计划及关闭后不重排；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.23.exe，原 Data 和旧版 EXE 保留。
