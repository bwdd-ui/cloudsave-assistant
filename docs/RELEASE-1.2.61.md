# Windows 1.2.61 · 离线任务本地搜索

- 新增：离线任务 → 提交记录中的“搜索记录”输入框。按影片名称、磁力/链接、保存目录、反馈内容或媒体文件名查找；空格分隔的多个关键词需要同时匹配，兼容大小写和全角字符。
- 新增：搜索覆盖全部已加载记录后再分页，可与来源、提交状态和115云下载状态组合使用；清空按钮或 Esc 可清除关键词。
- 优化：输入暂停180毫秒后更新，避免连续打字反复绘制；搜索不访问网站或网盘。搜索只影响显示，提取/导出全部历史仍包含全部记录，界面已明确提示。
- 修复：提取全部历史后的当前显示计数复用界面筛选结果，包含关键词及115任务视图，不再单独计算一套计数。

使用入口：左侧“离线任务” → “提交记录” → 本地提交记录卡片“搜索记录”。如果按115云下载状态查看任务，可继续使用同一搜索框查找其缓存记录。

验证：106 项回归测试；新增关键词跨字段匹配、中文/大小写/全角处理、万条记录和浏览器模块测试。隔离 Data 的真实 Electron 界面验证跨页查找、页码重置、来源组合、Esc清空、115缓存搜索，以及1500/1040/800窗口布局，并保留截图。打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。
