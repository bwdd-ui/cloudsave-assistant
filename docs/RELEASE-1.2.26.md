# Windows 1.2.26 · 网盘监控异常日期校验

网盘分享监控在解析年月日格式前校验日历合法性，避免 Date.parse 把不存在的日期自动折算到下个月，导致异常资源误通过最近天数筛选。

覆盖横线、斜线、中文年月日及这些日期前缀的时间戳；合法闰日、正常日期和相对日期保留。关闭日期筛选时仍保持原有行为，不更改历史跳过记录。

验证：71 项回归测试，覆盖二月三十日、非闰年二月二十九日、大小月边界及合法闰日；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.26.exe，原 Data 和旧版 EXE 保留。
