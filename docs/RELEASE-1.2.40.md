# Windows 1.2.40 · 视频格式空白兼容

修复网盘分享格式筛选对文件名末尾空白识别不准确的问题。文件名包含首尾空格、制表符、换行或全角空格时，现在仍可正确识别扩展名，避免默认跳过格式漏判或所需格式误判缺失。

只在格式判断时清理首尾空白，原始文件名不修改。任一/全部所需格式、跳过格式优先和文件名缺失保护保留。

验证：85 项回归测试，新增各文件名字段、空白类型及模拟监控整份分享拦截测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.40.exe，原 Data 和旧版 EXE 保留。
