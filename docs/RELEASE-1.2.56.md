# Windows 1.2.56 · 云下载分页完整性保护

修复 115 云下载分页总数的异常类型可能被数字转换接受，以及全部同步过程中页数变化仍被认定完整的问题。页数仅接受数字或非空数字字符串，并继续检查整数及原有范围；全部同步要求后续页面的总页数与首个页面一致。

遇到格式异常或全部同步页数变化时，停止本轮同步并保留原缓存，不推进完整同步时间点，避免把不完整扫描当作完整基线。正常数字/数字字符串、历史累计任务、增量同步缺少可选页数时的单页兼容保持原有行为。

验证：101 项回归测试，新增异常页数类型、全部同步中总页数增加/减少、失败不写入或推进缓存、合法数字/字符串及增量缺少页数兼容测试。旧版异常类型误接受已复现。隔离 Data 的 Electron 界面检查、打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.56.exe，原 Data 和旧版 EXE 保留。
