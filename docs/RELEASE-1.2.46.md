# Windows 1.2.46 · 保存核验大小保护

修复 115 保存目标目录核验中，空白或布尔值等异常大小可能被当作 0、1 字节匹配的问题。源文件和目标文件现在都要求有效的非负安全整数字节数。

大小信息异常时不会误认定保存成功，已提交请求仍保留未确认状态，不自动重复转存。正常数字字符串和零字节文件继续支持。

验证：91 项回归测试，新增源/目标异常大小、正常边界和模拟接口只提交一次测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.46.exe，原 Data 和旧版 EXE 保留。
