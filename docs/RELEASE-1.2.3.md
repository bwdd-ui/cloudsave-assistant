# 云存助手 Windows 1.2.3 · 独立文件保存与导出失败恢复

本轮只发布 Windows x64 完整 EXE，其他平台安装包保持原版本。

- 后台写入按文件确认结果。一个 Excel 导出或缓存文件无法写入时，其他独立的设置和缓存仍继续保存；成功写入的文件不再反复重写，只保留失败项重试。
- 归档文件与归档索引保留先后关系：归档文件保存失败时不提前覆盖对应数据库索引，避免产生缺失记录；其他独立设置仍可保存。
- Excel 导出已向用户报告失败后，取消该次工作簿的后台自动重试。用户可换位置重新导出，不再被旧的失败导出阻塞退出。关键 JSON 数据失败仍保留并重试。
- 修复一个待保存的 null 值错误读取为更旧的在途值的问题。

新增真实后台写入线程测试，覆盖单文件失败隔离、归档索引屏障、导出换路径重试和 null 覆盖。主要回归共47组。测试使用独立临时目录和模拟记录，未操作真实网盘或用户 Data。

下载 `CloudSave-Windows-1.2.3.exe`。退出旧程序及托盘实例后在原 Data 目录旁运行；原数据与旧版程序保留。公开包仅包含运行程序、源码、说明和校验信息。
