# Windows 1.2.22 · 筛选分页缓存容量修复

修复多个筛选请求同时读取时，分页缓存临时超过容量后不再清理的问题。读取结束或失败后重新整理空闲缓存，使容量收敛至配置上限，不驱逐仍在读取的筛选状态。

重复访问的筛选移至最近使用位置，优先保留常用结果，减少切换回来时重复补齐。原有全局筛选顺序、跨页补齐、失败重试和读取去重保持不变。不会清空磁力历史、任务或账户配置。

验证：67 项回归测试；六组并发筛选全部正常完成后回到两组测试容量，最近使用缓存保留，失败收尾及重试通过。隔离 Data 的 Electron 界面检查和打包校验通过，未使用真实账号转存。只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.22.exe，原 Data 和旧版 EXE 保留。
