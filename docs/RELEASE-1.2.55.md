# Windows 1.2.55 · 云下载等待停止保护

修复 115 云下载同步等待分页请求间隔或旧任务核查间隔期间，程序开始退出或账号已切换，但等待结束后仍多发一次请求的问题。现在两处间隔等待完成后，发送下一次请求前重新确认退出状态和账号。

中止的同步保留原有缓存，不提交暂存结果；正常分页仍按原间隔执行。保留累计缓存、增量同步和每轮旧任务核查上限，不改变已经发送的网络请求。

验证：100 项回归测试，新增停止/切换账号发生于分页及状态核查等待期间的四组测试，确认不多发请求、不写入缓存、释放同步状态，并验证正常分页可完成。旧版额外请求已复现。隔离 Data 的 Electron 界面检查、打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.55.exe，原 Data 和旧版 EXE 保留。
