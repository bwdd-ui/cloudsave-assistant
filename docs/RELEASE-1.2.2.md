# 云存助手 Windows 1.2.2 · 海报缓存恢复

本轮只更新 Windows x64 完整 EXE。Docker、飞牛 FPK 和 Android 不更新。

- 修复海报缓存为有效 JSON、但缺少或损坏图片字段时长期显示空白的问题：验证缓存来源和图片数据，异常缓存重新下载并修复。
- 修复图片已下载成功、但缓存目录无法写入时仍被丢弃的问题：缓存写入失败不会阻止本次海报显示，也不会为同一图片再重复下载一次。
- 修复封面并发队列交接时的名额争抢：等待中的请求保留名额，新请求不会抢占并突破并发上限。

新增针对损坏缓存、错误来源、缓存目录不可写和队列交接的回归测试。主要回归共46组；打包后核对运行源码、版本和文件白名单。

下载 `CloudSave-Windows-1.2.2.exe`。先退出旧程序及托盘实例，再在原 Data 目录旁运行新版；账号、任务、断点和历史沿用原 Data。公开发布包不包含私人 Data 或登录信息。测试使用独立临时目录和模拟图片响应，未执行真实网盘转存。
