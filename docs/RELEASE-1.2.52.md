# Windows 1.2.52 · 筛选列表异常恢复

修复筛选跨页补齐时，网站响应缺少资源列表或列表类型异常，被误判为空列表、已到末页并缓存的问题。现在明确提示列表格式异常，不把异常响应当作正常结束。

首次加载和补齐中途出现异常时，保留已有匹配资源、源页码和计数，重试从失败的源页面继续，不重复扫描已经成功的页面。网站明确返回空数组时仍正常结束，筛选排序和原生每页数量保持原有规则。

验证：97 项回归测试，新增缺失/null/布尔值/字符串/对象列表校验、首次及中途失败进度保护、原页重试、合法空列表结束测试。旧版误判空列表问题已复现。隔离 Data 的 Electron 界面检查、打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.52.exe，原 Data 和旧版 EXE 保留。
