# Windows 1.2.38 · 观影子路径会话保存

修复观影会话备份只读取根路径 Cookie 的问题。现在读取该站所有路径的 Cookie，并过滤其他域名，避免子路径登录状态遗漏备份。

恢复时也使用完整路径视图识别浏览器中已续期的 Cookie，防止旧备份覆盖较新的子路径会话。正常缺失 Cookie 恢复、加密保存和网站存储规则保留。

验证：83 项回归测试，另用隔离 Electron 会话实际验证子路径备份、续期会话保留和其他域名排除；隔离界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.38.exe，原 Data 和旧版 EXE 保留。
