# 云存助手 1.2.1 · 页面布局优化

## 更容易找到操作入口

- 左侧仍按资源库、盘搜、自动监控、管理分组，分组可以折叠。切换页面后自动展开当前分组，避免长导航不断向下滚动。
- 五个网站的监控入口缩短为“站名监控”，完整名称保留在悬停提示和无障碍标签中；页面内继续区分磁力监控与网盘监控。
- 每页顶部增加固定的当前位置和快捷入口：同一网站资源库/监控互相切换、离线任务、任务日志、设置。长页面滚动后仍可操作。
- 监控页面可直接跳到磁力设置或网盘任务，两套配置继续在同一页面展示。

## 页面信息顺序

监控先显示标题和本站保存开关，再显示检查间隔、运行操作、大小和时间条件。网站的详细类型/年代/地区等筛选收进可展开区域；仅采集和 Excel 导出说明放在筛选下方。原来的表单节点、选中值、事件处理和任务草稿保留。

设置的“返回”回到进入设置前的页面，避免从监控进入设置后跳回资源库首页。离线任务的筛选和操作栏统一间距，账户配置入口按固定的适度尺寸排布。

## 版本与验证

本版延续1.2.0的数据写入恢复、请求退避、海报按可见区域加载和账号隔离优化。45组回归测试，以及真实 Electron 导航、分组、监控内嵌任务和设置返回检查通过。Docker真实容器和飞牛模拟生命周期验证另见对应发布资产；飞牛没有进行真实设备安装验证。

Windows 下载 `CloudSave-Windows-1.2.1.exe`，退出旧程序后放到自己的原 Data 目录旁运行。公开源码和程序不包含任何用户的账号或 Data。
