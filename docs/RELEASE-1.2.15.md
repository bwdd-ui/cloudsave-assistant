# Windows 1.2.15 · 网盘监控旧任务调度恢复

修复网盘分享监控的到期判断不一致：缺失或异常的下次运行时间原先可能反复唤醒定时器，却没有真正选中任务。本版统一按到期处理，使已启用的旧任务恢复调度，完成后沿用正常间隔；关闭的任务和未来到期任务保持原有行为。

过远的计划时间按 Node 定时器安全范围分段等待，防止超长时间溢出后变成高频空转。保留任务配置、历史记录和正常运行任务。

验证：60 项回归测试，覆盖旧任务时间缺失、无效值、关闭任务、未来任务及超长等待；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，未修改用户 Data。仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后，再运行 CloudSave-Windows-1.2.15.exe。原 Data 和旧版 EXE 保留。
