# Windows 1.2.21 · 取消读取后立即清理队列

网站读取任务取消时，尚未执行的队列项立即移除。此前调用方虽然已收到取消结果，队列项仍可能停留到前一个读取完成；大量停止操作会留下无用排队和排序工作。

保留原取消原因、读取优先级和超时规则，不打断其他仍有效的读取任务。新任务可以正常接续，已取消任务不会执行。

验证：66 项回归测试；在前一个读取阻塞时取消 100 个等待任务，队列立即清空，原任务和后续有效任务正常完成。隔离 Data 的 Electron 界面检查和打包校验通过，未使用真实账号转存。只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.21.exe，原 Data 和旧版 EXE 保留。
