# 2026-10-12 聚影退避与并行监控版

- 磁力与网盘监控标题明确区分。
- 多个资源库的网盘任务可同时运行，支持单任务停止与全部停止。
- 同一网盘账号的相同链接共享历史及并发锁，减少重复转存。
- 聚影限流后统一暂停该站网络请求，读取 Retry-After 等重试时间；未给时间时逐步退避，保留扫描位置并到期重试。
- 聚影请求合并及缓存复用，基础请求间隔至少 5 秒，尊重更长的用户设置。

已交付版本通过 30 项主要回归测试以及聚影限速、并行任务、共享链接去重和界面专项测试。已检查安装包内 14 个相关运行文件与源码一致。测试主要使用模拟网站和网盘响应，未对用户真实网盘执行转存。新增多网盘适配仍为试运行。

本次 Release 提供 Windows x64 完整 EXE、整理后的源码 ZIP 和 SHA256 校验文件。安装包不包含私人 Data，更新时沿用自己的 Data。退出旧版本及托盘实例后再运行新版本。
