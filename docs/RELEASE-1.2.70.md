# Windows 1.2.70 · 清空离线记录筛选

## 新增功能

- 本版本没有新增独立功能。

## 优化

- 离线任务 → 提交记录的“清空筛选”现在一次重置来源、状态、115 云下载状态、关键词及日期范围，避免清除搜索后仍被隐藏筛选条件限制。
- 当只有来源、状态或云下载状态筛选生效时，“清空筛选”仍保持可用。键盘 Esc 仍只清除关键词，避免意外重置其他筛选。

## 修复

- 修复“清空筛选”按钮只清除关键词和日期、却保留来源与状态筛选的问题；按钮可用状态现在覆盖所有筛选项。

## 使用入口

离线任务 → 提交记录 → 使用来源、状态、115 云任务、关键词或日期筛选；点击“清空筛选”重置全部，或在搜索框按 Esc 仅清除关键词。

## 验证

`npm test` 全量模拟回归（111/111 测试文件通过）及桌面 Electron UI smoke。新增回归覆盖仅下拉筛选时按钮仍可用，以及来源、状态、云任务和日期等条件被完整清除。未使用真实账号或触发真实转存。
