# Windows 1.2.36 · 筛选分页参数保护

筛选分页新增页码及网站每页数量校验。小数、非有限数值及超出安全整数范围的页码不再切出错位结果或触发过量读取；网站返回异常每页数量时明确报错。

异常页不写入缓存，不推进断点，重试继续读取该页，保留之前成功的页面。数字字符串页码、正常原生每页数量和未提供数量时的兼容规则保留。

验证：81 项回归测试，新增非法页码、异常每页数量、断点保留及恢复重试测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.36.exe，原 Data 和旧版 EXE 保留。
