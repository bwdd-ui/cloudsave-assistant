# Windows 1.2.24 · 读取超时清理异常保护

网站读取超时或取消时，清理回调即使抛出异常，也会正常向调用方返回超时或取消结果，避免清理异常越过结果处理、使读取一直挂起。例如网页对象释放后，停止网页加载的清理可能抛错。

超时错误保留清理异常作为 cause 供诊断；取消仍保留原始原因。正常读取成功、读取本身失败、超时长度及排队规则不变。

验证：69 项回归测试，覆盖超时清理抛错、取消清理抛错、原始取消原因、正常完成及原始读取错误；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.24.exe，原 Data 和旧版 EXE 保留。
