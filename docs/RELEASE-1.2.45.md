# Windows 1.2.45 · 分享大小检查保护

修复 115 分享文件检查把空白字符串、布尔值等异常大小当作已知字节数的问题。现在只接受非负安全整数字节数，并检查累计总量是否超出精确整数范围。

大小信息不完整时标记为未知，不能据此通过已启用的大小筛选；正常整数、数字字符串及零字节文件仍可识别。

验证：90 项回归测试，新增异常大小类型、累计溢出和模拟监控拒绝不完整大小测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.45.exe，原 Data 和旧版 EXE 保留。
