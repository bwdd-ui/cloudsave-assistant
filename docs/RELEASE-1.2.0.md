# 云存助手 1.2.0 · 稳定性与加载体验优化

本版适用于 Windows x64、Docker linux/amd64 和飞牛 NAS x86-64 FPK。沿用原有 Data，保留账号配置、监控任务、采集断点和已保存链接历史。

## 实际改动

- 数据写入线程意外退出后自动重建，待保存数据保留；修复磁盘问题后可以立即再次保存，避免退出程序一直等待。JSON 缓存兼容 null 值。
- 缓存页面刷新失败后逐步退避 30 秒至 5 分钟，继续显示旧缓存，避免反复打开页面导致重复请求。退出时立即清理等待中的刷新任务。
- 切换 115 账号时，旧同步请求的结果或错误不会清除新账号待同步的磁力记录。关闭同步器后，在途请求不会重新启动定时器。
- 七味监控停止时取消请求间隔等待及在途网络请求；取消后不再写入新的详情缓存。
- 五个资源库共用海报加载器：接近可见区域时读取本地缓存或请求封面；离开当前页面的海报释放观察，迟到的结果不更新已移除卡片。失败时显示影片名称。
- 不太灵的海报卡片支持 Tab 聚焦、Enter/空格打开；键盘焦点可见。其他原有按钮卡片保留原生键盘行为。
- 主界面使用源码所在目录的绝对路径加载，兼容备用启动入口。
- 主要回归入口从 30 组扩大到 45 组，加入写入故障恢复、账号切换、海报懒加载、七味取消、跨库去重、并行分享、全量基线与增量同步等验证。

## 下载与升级

Windows 下载 `CloudSave-Windows-1.2.0.exe`。先退出旧程序及托盘实例，将新 EXE 放到原有 Data 旁运行；移动到其他位置时先备份再复制自己的完整 Data。

Docker 下载 `CloudSave-Docker-amd64-1.2.0.tar.gz` 和对应 Deploy 包，导入镜像后沿用 config/output 挂载并重新创建容器。访问 `https://NAS的IP:5800`。

飞牛下载 `CloudSave-fnOS-x86-1.2.0.fpk`，先启动 Docker 应用，再通过应用中心安装或升级。访问 `https://NAS的IP:18985`。

发布的源码和安装包不含用户 Data、真实 Cookie、账号密码或私人日志。新网盘适配仍需真实账号验证；本版模拟测试不代表第三方接口永久可用。Docker 验证使用真实容器，飞牛生命周期测试使用模拟环境，不代替真实 NAS 应用中心安装测试。

## 开发者

新增运行文件 `cloudsave-windows/ui-runtime.js` 已加入打包白名单。测试入口 `npm test`；真实 Electron 界面检查可运行 `node_modules/electron/dist/electron tests/smoke-desktop.cjs`（Windows 使用 electron.exe）。测试使用独立临时 Data 和合成资源，不进行真实网盘转存。
