# Windows 1.2.58 · 聚影冷静期异常恢复

修复聚影网站重试时间为无穷大或超出可表示日期范围的数字时，可能生成无法到期的冷静期。现在只接受有效的数字或非空数字字符串延迟，且生成的到期时间必须有效。

异常响应头优先尝试合法的响应体重试时间，否则使用原有 15–60 分钟退避。布尔、数组等响应体类型不再被当作秒数。合法秒数、小数向上取整和网站给出的未来日期仍受遵守，不提前绕过网站冷静期。

验证：103 项回归测试，新增无穷/超大/异常类型的重试时间、合法秒数与日期兼容，以及模拟限流后的暂停和到期恢复测试。旧版无限冷静期已复现。隔离 Data 的 Electron 界面检查、打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.58.exe，原 Data 和旧版 EXE 保留。
