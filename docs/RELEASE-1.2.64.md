# Windows 1.2.64 · 按筛选结果导出提交记录

- 新增：离线任务 → 提交记录新增“导出当前筛选为Excel”，只导出当前来源、状态、关键词和115任务视图共同筛出的本地提交记录；显示匹配数量，未关联到本地提交历史的云端任务不会混入。
- 优化：筛选导出沿用原有媒体信息缓存补全、Excel列和保存位置选择；“导出全部历史为Excel”仍可导出完整提交历史。
- 修复：筛选导出只接受本地历史中已有的链接标识，并限制IPC参数数量和长度，避免界面请求制造或导出不存在的记录。

使用入口：左侧“离线任务” → “提交记录” → 设置来源、状态或搜索词 → 点击“导出当前筛选为Excel（数量）”。如需完整历史，使用旁边的“导出全部历史为Excel”。云端任务只有在能匹配到本地提交记录时才会进入筛选导出。

验证：109项回归测试；实际Electron界面确认关注筛选下导出按钮显示3条并可用，筛选点击将22条匹配记录键传入导出接口，IPC筛选工具覆盖精确匹配、重复键、空选择、输入边界及不改写历史记录。隔离测试目录与用户Data分离，未触发真实保存或转存。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.64.exe，原 Data 和旧版 EXE 保留。
