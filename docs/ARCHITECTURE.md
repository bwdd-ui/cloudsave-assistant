# 架构与移交

## 代码结构

`cloudsave-windows/main.js` 为 Electron 主进程入口，负责窗口、会话、登录、IPC 和服务调度；`preload.js` 向页面提供受控 IPC API；`renderer.js` 与各网站 renderer 文件负责界面。`index.html` 与主题 CSS 提供应用布局。

各站 provider 文件负责网站目录、详情和资源解析；monitor 文件负责筛选、调度、缓存、断点和历史。`share115-monitor.js` 承载网盘分享任务与跨资源库共享历史；具体网盘适配按源码中的 provider 接口处理登录、文件列表、目标目录和保存操作。名称中含 115 的文件也可能包含后续扩展的多网盘功能。

`jying-rate-limit.js` 提供聚影共享网络队列及持久冷静期。单个任务互斥，不同任务允许同时运行；相同账号的重复链接通过共享历史与处理中链接锁避免重复保存。网站级限速独立于任务并发。

## 本地数据与升级

运行配置、Cookie、采集结果、离线历史、网盘任务和状态缓存存于用户 Data。发布仓库故意不携带这些数据。修改数据结构应兼容已有 JSON 字段；保存任务配置不应等待扫描结束。写缓存需防止并发覆盖。重建安装包不应清空、覆盖用户 Data。

磁力采集历史和网盘已保存链接历史用途不同：前者记录网站资源及媒体信息，后者用于去重和断点恢复。未知发布时间或文件信息不能假定已覆盖；大小判断须区分电影、剧集及逐集策略。

## 依赖及可复现范围

锁定依赖见 package-lock.json；运行时打包白名单见 package.json 的 build.files。安装包为 Windows x64 Electron 便携版。源码可以重建相同功能；构建时间、Electron 打包工具及签名状态可能使二进制哈希不同。发布 EXE 是已交付的完整版本，仓库中的中文打包元数据及 README 经公开发布整理。

现有中文专题说明位于应用源码目录。涉及历史实现的说明应结合当前代码阅读，最新聚影并行说明和本仓库 README 优先。测试涵盖模拟响应，不表示所有第三方接口均已通过真实账号验证。

## 开发注意事项

- 改动登录路径时保留持久会话分区和现有用户数据目录，避免升级后反复验证。
- 禁止在日志、测试样例和 Git 中写入真实 Cookie、令牌或用户密码。
- 不将网络错误当作空资源列表或已完成扫描；保留当前位置并按限速重试。
- 网盘写入必须使用明确目标文件夹；任务历史要兼容用户事后移动文件的行为。
- 扩展网站或网盘时分别验证分页、更新时间、文件格式、目录和全局去重。
