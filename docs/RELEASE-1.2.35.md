# Windows 1.2.35 · 磁力更新时间校验

修复磁力监控“最近多少分钟”筛选中，带时分秒的非法日历日期可能被自动换算成有效日期的问题。例如 2 月 30 日、非闰年的 2 月 29 日及 4 月 31 日，不再误通过最近更新时间筛选。

更新时间选择时也会跳过这些异常精确时间，继续使用其他有效字段。正常闰日、时区、仅日期和相对时间规则保留。

验证：80 项回归测试，新增非法时间戳及有效字段回退测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.35.exe，原 Data 和旧版 EXE 保留。
