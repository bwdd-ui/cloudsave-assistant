# Windows 1.2.34 · 归档缓存更新修复

修复历史资源归档保存替换记录后，内存读取缓存可能仍返回旧对象的问题。保存归档更新时现在会清除对应旧缓存，后续读取使用最新待写入快照或磁盘记录。

保持现有归档文件、资源身份校验和活动记录优先规则，不迁移或清空用户历史。

验证：79 项回归测试，新增实际写入线程测试，覆盖更新前缓存命中、写盘前读取、状态与资源信息更新、连续替换及重启恢复；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.34.exe，原 Data 和旧版 EXE 保留。
