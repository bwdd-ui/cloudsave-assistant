# Windows 1.2.32 · 同步时钟恢复

修复 115 云下载缓存时间异常或系统时间回拨后，自动同步可能长期认为间隔未到的问题。同步节流和界面显示的下次同步时间现在使用同一套有效检查点，只接受不晚于当前时间的有限正数时间。

异常检查点不再推迟同步；恢复时继续增量更新并保留此前缓存的任务，成功后恢复正常间隔。正常检查点、失败尝试间隔和账号隔离继续生效。

验证：77 项回归测试，新增未来时间、非有限数值及异常文本恢复测试，覆盖历史保留、成功后节流、有效检查点和账号隔离；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.32.exe，原 Data 和旧版 EXE 保留。
