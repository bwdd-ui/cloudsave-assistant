# Windows 1.2.16 · 监控状态刷新减负

网盘监控刷新最近转存记录时，已保存任务编号与名称的记录不再逐条扫描日志推断归属；任务查找改为一次建立索引。减少持续监控和界面刷新期间的重复字符串比较。

旧记录缺失任务信息时仍从日志兼容恢复；多条日志指向不同任务时保留“历史任务（未记录名称）”，避免误归属。最近 100 条、时间排序、保存时任务名和文件数量保持原有规则。不删除或截断已有历史数据。

验证：61 项回归测试；100 条现代记录、500 条日志的状态读取不访问日志消息，旧记录归属、歧义处理及排序数量均通过。隔离 Data 的 Electron 界面检查和打包校验通过，未使用真实账号转存。只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.16.exe，原 Data 和旧版 EXE 保留。
