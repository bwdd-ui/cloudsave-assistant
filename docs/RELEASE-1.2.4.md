# 云存助手 Windows 1.2.4 · 退出保存稳定性

本轮只发布 Windows x64 完整 EXE，其他平台安装包保持原版本。

- 修复退出保存期间连续点击退出会重复关闭网站模块、重复发起数据写入和退出的问题。同一次退出只执行一次清理与保存，后续退出请求等待其完成。
- 网站模块清理的同步异常也纳入错误处理，失败时保留程序并提示原因；处理问题后可以再次退出重试。
- 保留等待监控、导出和数据保存完成后才退出的行为。

新增实际主进程退出处理代码的隔离回归，覆盖连续20次退出请求、同步清理失败、磁盘保存失败和再次退出恢复。主要回归共48组，未启动真实监控或操作用户 Data、真实网盘。

下载 CloudSave-Windows-1.2.4.exe。退出旧程序及托盘实例后，在原 Data 目录旁运行新程序；原数据与旧版程序保留。
