# Windows 1.2.63 · 待处理任务快速筛选

- 新增：离线任务 → 提交记录的“需要关注”计数按钮，集中查看提交失败、提交待确认及保存目录异常的记录。
- 新增：提交结果下拉菜单可分别选择“需要关注”“提交失败”“提交待确认”“保存目录异常”，与来源、关键词搜索组合筛选，筛选后可直接复制匹配链接。
- 优化：提交记录统计采用均衡的两列布局，避免新增关注按钮单独挤到一行。
- 修复：在115云下载状态视图中选择本地来源或提交状态时，正确切回本地记录，避免筛选被云下载视图忽略。
- 修复：历史已接受记录显示为“历史已接受”，继续属于已成功提交范围，不因状态标签缺失而被当作失败或混入需要关注列表。

使用入口：左侧“离线任务” → “提交记录” → 点击“需要关注”，或在“提交结果”下拉菜单选择具体状态。此功能只筛选已有记录，不会自动重试离线或转存；“提交待确认”仍需核对实际网盘结果后处理。

验证：108 项回归测试；新增关注状态组合、单独状态、历史已接受排除及菜单入口测试。隔离 Data 的真实 Electron 界面验证75条记录中筛出3条关注任务、复制3条匹配链接，再单独筛出1条目录异常记录，并保留截图；未改动系统剪贴板。打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.63.exe，原 Data 和旧版 EXE 保留。
