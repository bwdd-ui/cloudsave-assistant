# Windows 1.2.48 · 筛选缓存停止保护

修复筛选分页缓存足够时跳过停止检查的问题。已经取消的读取现在即使命中缓存，也不会返回成功结果；排队等待同一筛选读取的请求，在轮到执行时会重新检查停止状态。

取消不会清空有效缓存，下次正常读取仍可复用，也不会额外发起网站请求。

验证：93 项回归测试，新增首次读取、缓存命中、排队等待期间取消及缓存继续复用测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.48.exe，原 Data 和旧版 EXE 保留。
