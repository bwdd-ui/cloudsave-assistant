# 云存助手 Windows 1.2.11 · 115转存目标目录核验

针对接口表示接受、但用户目标目录中找不到资源的问题，115分享监控转存后增加只读核验，不再直接把接口接受当作保存完成。

- 读取并确认实际目标目录ID，完整读取其分页。按名称、大小及双方可用的校验值匹配；源目录逐层读取并与目标子目录核对，不能只看到同名空文件夹就判定成功。
- 支持短暂延迟可见的二次只读核验。核验缺失、分页异常、目录不符或停止任务时记录待核对状态，保留接口反馈；绝不为了核验重发转存POST。设置层级、文件及请求数量上限，异常时保守保留待核验状态。
- 通过核验才记录已核验；原有历史接受记录显示目录未核验，保留历史去重和用户数据，不擅自重新转存。用户核对后可按原入口确认或允许重试。
- 其他网盘的接口接受仍明确显示目录尚未核验，不冒充已验证。

56组回归和真实Electron隔离界面检查通过，包括真实适配器与监控组合的模拟转存、空壳目录、校验不符、错误目录、延迟可见及停止。没有使用真实账号发起转存或修改用户Data。只构建发布Windows x64完整EXE。

使用前退出旧程序及托盘实例，在原Data旁运行 CloudSave-Windows-1.2.11.exe。当前已运行的旧版不会因复制新EXE而自动升级。
