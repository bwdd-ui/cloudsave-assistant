# Windows 1.2.43 · 筛选缓存时钟恢复

修复系统时间回拨后，筛选分页缓存年龄变成负数、旧结果可能被保留过久的问题。已完成的缓存遇到负年龄或达到有效期时，会重新读取资源。

正在读取的分页任务继续复用，不因时间回拨被驱逐或重复启动；完成后记录当前时钟。正常缓存复用和跨页补齐规则保留。

验证：88 项回归测试，新增有效期边界、时钟回拨、活动读取保留和完成后缓存复用测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.43.exe，原 Data 和旧版 EXE 保留。
