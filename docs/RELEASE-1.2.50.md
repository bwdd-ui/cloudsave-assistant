# Windows 1.2.50 · 提交后同步日志保护

修复磁力提交后，日志写入异常会中断 115 云下载增量同步的问题。现在日志回调失败不会阻止实际同步，也不会破坏失败后的有限重试，成功后正常完成并释放待同步标记。

同时修复上一版海报缓存对 Windows 亚毫秒文件时间的误判：同一毫秒内刚写入的缓存可正常复用，真正未来时间和过期缓存仍重新读取，避免偶发重复下载。

保留原有合并提交、账户隔离、同步限速和最多两次重试规则。后续新提交仍能继续触发同步。

验证：95 项回归测试，新增日志失败时仍同步成功、真实同步失败仅重试两次、后续恢复及关闭保护；旧版日志异常中断问题已复现；增加海报亚毫秒时间回归，修复回归发现的问题。隔离 Data 的 Electron 界面检查、打包代码核对、源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.50.exe，原 Data 和旧版 EXE 保留。
