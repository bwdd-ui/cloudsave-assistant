# Windows 1.2.27 · 网盘监控异常大小校验

修复无限大数值在仅设置最小资源大小时可能通过筛选的问题，负数字符串也不再被当作正大小。非有限数值、数字溢出及异常数字文本按大小未知处理，不能通过已开启的大小筛选。

保留正常 GB/GiB、MB/MiB、TB、KB、字节换算及大小范围的包含边界规则。没有开启大小筛选时仍按原规则处理；不修改已保存链接、账户或任务配置。

验证：72 项回归测试，覆盖无限大绕过、负数、异常小数、数值溢出、单位换算及上下边界；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.27.exe，原 Data 和旧版 EXE 保留。
