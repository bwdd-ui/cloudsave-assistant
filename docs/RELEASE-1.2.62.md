# Windows 1.2.62 · 复制筛选链接

- 新增：离线任务 → 提交记录中的“复制筛选链接”按钮。使用当前关键词、来源、提交状态或115云下载状态的筛选结果，复制所有匹配页的有效磁力、ed2k或网页链接，每行一条。
- 优化：重复的相同链接只复制一次，按钮显示可复制数量，没有匹配链接时禁用；空链接、非支持协议和包含换行的异常链接不进入复制内容。
- 兼容：原“提取全部历史”与“导出全部历史”继续保留全部记录的语义。新功能只写入用户主动点击时的剪贴板，不创建离线任务或转存操作，也不修改历史。

使用入口：左侧“离线任务” → “提交记录”，先搜索或选择来源/状态，再点击“复制筛选链接”。不输入关键词时也可复制该视图所有匹配链接。

验证：107 项回归测试；新增跨页/去重/协议/空值/换行与不修改记录测试，并扩展界面回归验证筛选复制、131条跨页复制和零匹配保护。隔离 Data 的真实 Electron 界面用模拟剪贴板验证单条筛选及75条跨页去重为74条；未改动系统剪贴板，未使用真实账号或实际网盘转存。打包代码核对及源码隐私检查通过，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.62.exe，原 Data 和旧版 EXE 保留。
