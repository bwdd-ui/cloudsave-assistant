# Windows 1.2.14 · 分享监控停止边界修复

修复 115 分享列表在翻页等待期间停止监控，等待结束后仍可能多读取一页的问题。等待结束立即重新检查任务状态；转存提交之前也增加最后一次停止检查。

停止发生在提交前时，不发送转存 POST；已经发出 POST 后才停止的结果仍保留为待核对，不自动重复提交，避免重复转存。显式手动调用仍兼容原有行为。

验证：59 项回归测试，覆盖翻页等待停止、提交前停止、提交后停止及正常提交；完成隔离 Data 的 Electron 界面检查和打包校验。未使用真实账号进行转存，未修改用户 Data。仅发布 Windows x64 完整 EXE。

从托盘退出旧版后，运行 CloudSave-Windows-1.2.14.exe。原 Data 和旧版程序保留。
