# Windows 1.2.20 · 资源缓存异常恢复

资源列表磁盘缓存载入时校验根对象、条目结构、键和时间戳，跳过损坏记录，保留有效记录。避免异常条目在容量清理排序时抛错，未来时间戳也不再长期被当成新缓存。

启动载入与后续写入都遵守缓存容量上限；系统时钟回拨时，未来缓存会重新读取。正常缓存命中、过期边界和清理规则保留。只整理资源缓存，不修改账户、任务或转存历史。

验证：65 项回归测试，覆盖异常缓存、有效缓存保留、未来时间戳、时钟回拨、过期边界及启动容量限制；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.20.exe，原 Data 和旧版 EXE 保留。
