# Windows 1.2.37 · 登录会话路径修复

修复网站网络回退通道处理过期 Cookie 时使用根路径删除的问题。子路径 Cookie 过期后现在按原名称、域和路径处理，避免删除同名根路径 Cookie，却留下本应过期的登录状态。

未声明 Path 或声明无效相对路径时使用请求的默认 Cookie 路径；正常登录续期、安全属性及域隔离保留。

验证：82 项回归测试，另用隔离 Electron 会话实际验证子路径过期、同名根路径和更深路径保留、默认路径及 Expires 过期；隔离界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.37.exe，原 Data 和旧版 EXE 保留。
