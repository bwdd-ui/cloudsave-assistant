# Windows 1.2.25 · 相对日期筛选边界修复

网盘分享监控的日期筛选改为一次判断共用同一个当前时间。此前解析“昨天”“1天前”和计算最近天数截止时间分别读取时钟，可能因几毫秒差异误排除正好处于边界的资源。

保留最近天数的原有包含边界规则；更早资源、缺失时间、未来时间上限及大小筛选保持原样。不修改已保存链接历史，也不批量重试旧记录。

验证：70 项回归测试，覆盖时钟在判断期间前进、昨天/昨日/1天前/24小时前、精确边界及大小筛选；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.25.exe，原 Data 和旧版 EXE 保留。
