# Windows 1.2.49 · 海报缓存时钟恢复

修复海报磁盘缓存遇到系统时间回调时仍被当作有效缓存的问题。文件时间晚于当前时间时，现在重新读取封面，避免旧封面长期无法更新；正常缓存继续复用，恰好达到有效期的缓存会刷新。

验证：94 项回归测试，新增未来文件时间、有效期边界、正常缓存复用及刷新写回测试；隔离 Data 的 Electron 界面检查和打包校验通过。旧版问题已在隔离测试中复现。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.49.exe，原 Data 和旧版 EXE 保留。
