# Windows 1.2.44 · 导出字符兼容修复

修复 Excel 导出未过滤 U+FFFE、U+FFFF 两个 XML 非法字符的问题。网站标题或资源描述包含这些字符时，不再将它们写入工作簿 XML，避免文件打开失败或提示修复。

中文、表情、制表符和换行继续保留，XML 特殊字符继续转义，导出列及原始历史数据不修改。

验证：89 项回归测试，新增工作簿 XML 各部分、单元格、表头和工作表名称字符测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.44.exe，原 Data 和旧版 EXE 保留。
