# Windows 1.2.47 · 分享分页完整性保护

修复 115 分享及目标目录分页将空白、布尔值等异常总数转换成 0 的问题。分页总数现在要求有效的非负安全整数，避免把异常响应误认为完整空列表。

正常空目录的数值 0 和数字字符串继续支持。递归保存核验遇到异常分页时保留未确认状态，不自动重复提交转存。

验证：92 项回归测试，新增源/目标分页总数类型、正常空目录和递归核验单次提交测试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号或实际网盘转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.47.exe，原 Data 和旧版 EXE 保留。
