# Windows 1.2.30 · 退出前保存保护

修复后台写入线程关闭时的保存竞态：前一批写入完成的回调若紧接着产生新配置或历史快照，关闭流程现在会继续排空这些待写入数据，再关闭线程，避免遗漏退出前的最后一次修改。

写入失败时仍保留待保存数据并反馈失败，修复磁盘问题后可以重试；保留账户、任务配置和历史数据。

验证：75 项回归测试，新增实际写入线程测试，覆盖连续两轮完成回调追加更新、最终空值快照、重复关闭和磁盘失败后重试；隔离 Data 的 Electron 界面检查和打包校验通过。未使用真实账号转存，只发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.30.exe，原 Data 和旧版 EXE 保留。
