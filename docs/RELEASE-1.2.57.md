# Windows 1.2.57 · 后台保存重试恢复

修复向后台写入线程发送数据时同步抛出异常后，只保留待保存记录，却未安排自动重试的问题。现在此类失败也进入既有重试调度，无需再次修改设置或手动触发保存。

保留原有至少一秒的失败重试间隔和待写记录；手动 flush 仍向调用方报告当次失败。临时发送故障恢复后会自动写入，失败的一次性 Excel 导出仍会移除，不留下无意义的导出重试。

验证：102 项回归测试，新增手动 flush 和后台延迟保存两种发送异常路径，使用临时目录及真实写入线程验证自动恢复、重试间隔、JSON 内容、状态清理及不可克隆导出清理。旧版缺少重试调度已复现。隔离 Data 的 Electron 界面检查、打包代码核对及源码隐私检查通过。未使用真实账号或实际网盘转存，仅发布 Windows x64 完整 EXE。

请从托盘退出旧版后运行 CloudSave-Windows-1.2.57.exe，原 Data 和旧版 EXE 保留。
