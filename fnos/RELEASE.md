# 云存助手飞牛 NAS FPK 1.2.1（x86-64）

基于已验证的 Docker 版，重新使用飞牛官方 fnpack 1.2.3 制作安装包。包含完整 amd64 镜像，无需安装时联网拉取；请先安装并启动飞牛 Docker 应用。

在应用中心选择手动安装 FPK，按向导设置管理用户名和密码。启动完成后点击打开，或访问 `https://NAS的IP:18985`。应用标识保持 cloudsave，Data 继续位于应用 var/Data，共享导出目录为 cloudsave/exports。关闭浏览器不会停止监控。

修正旧包中文编码和重复回车；安装回调校验并导入镜像，状态检查返回真实容器运行状态；支持配置管理密码、保留历史和迁移旧管理登录。

验证包括官方打包器、包内校验、Linux 脚本、模拟飞牛环境的安装/配置/升级回调，以及实际 Docker 启动和重启。**尚未连接真实飞牛设备完成应用中心安装验证**；网盘真实账号适配的试运行状态与 Docker 版一致。
