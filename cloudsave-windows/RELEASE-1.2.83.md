# Windows 1.2.83

## 新增功能
- 自动监控页显示当前 115 账户等待下载完成和目录核验的任务数，并提示在“离线任务”页筛选“已提交/待核对”查看。计数按当前登录账户隔离，排除重复队列项及已核实记录。

## 优化
- 监控进行中和空闲状态均显示待核验数，任务完成/核验后的推送状态会同步刷新提示。

## 修复
- 修正监控界面此前无法直接辨认 115 已接受、但尚未实际完成下载或保存目录核验的任务数量的问题。

## 验证
- 回归测试：`npm test`，115/115 测试文件通过。
- 新增覆盖：当前账户隔离、重复项去重、已核验项排除、账户切换，以及监控页有待核验/归零时的提示。
- 构建目标：Windows x64 完整 EXE（不包含 Docker、飞牛 FPK、Android 或轻量版）。

## 使用入口
- 打开“自动监控不太灵磁力链接”页面，查看状态区中的“等待115下载完成与目录核验”提示。
- 点击左侧“离线任务”，将状态筛选设为“已提交/待核对”查看记录。该显示只读取本地队列，不会自动发起新的离线或转存操作。
