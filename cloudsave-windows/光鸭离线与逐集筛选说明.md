# Windows更新：光鸭离线、逐集大小与历史Data合并

日期：2026-10-09。此版沿用完整Electron Windows x64版本；本次未修改安卓与NAS。

## 光鸭云盘

设置首页增加“光鸭云盘”账户方块。点击进入，使用“打开光鸭登录”，在官方网页窗口扫码或短信登录；无需在软件中输入账户密码。登录完成后点击刷新状态，然后“选择保存文件夹”，逐层打开目录，点击“使用当前文件夹”。根目录只有明确选择时才使用，目录不存在或账号不匹配时停止提交。

各资源库海报详情中的磁力行增加“添加到光鸭”。离线任务新增“光鸭离线”选项，支持每行一个磁力/ed2k，最多50条，按顺序提交。停止按钮停止尚未开始的后续提交，已经发出的请求需要返回，不撤回云盘任务。当前光鸭功能为手动和批量提交；现有自动监控的磁力自动提交仍使用115，不改变其去重及云下载状态比较。

光鸭与115分别登录、设置目标文件夹、记录任务。光鸭记录不计入115下载数量。“光鸭已接受”表示接口返回了任务ID，不代表云盘已经下载完成。当前界面展示本地提交结果，不轮询光鸭云端进度。下载是否完成请打开光鸭网页查看。

光鸭登录凭据使用已有本地加密工具保存在Data/config.json，官网浏览器会话使用独立persist:cloudsave-guangya分区。没有向界面暴露Token，也没有将Token写入日志。Token失效后打开官网登录窗口，网站可刷新有效会话，软件会保存新凭据；验证码/短信仍需用户在官网完成。本次不增加密码输入框，也不提供自动绕过验证。

离线只支持经过格式验证的magnet和ed2k。读取账户身份并重新核对选定文件夹后，解析资源，再向create_task提交明确parentId。合集传入服务器返回的文件索引。提交前持久化intent，网络超时或缺少任务ID时标记结果不明，不自动重复提交。先核对光鸭任务，再在记录中选择“核对后标记已提交”或“核对后允许重试”。成功记录按光鸭账户和磁力标识去重，再点击同一磁力会跳过；换文件夹不重新下载已接受的任务。

## 不太灵保存类型与剧集最小大小

自动监控不太灵顶部新增“只保存电影”“只保存电视剧”“电影＋电视剧”。选择后点击“保存筛选”或“立即检查”保存。此设置限制网站分类扫描、候选提交、本地失败资源下一档检查；不会只改变界面文字。电影和电视剧原有独立大小范围保留。

旧版的剧集最小GB只限制整条资源总大小，10GB合集可以包含500MB单集。这解释了设置最小1GB后仍可能看到小单集。

新版所有网站的剧集磁力自动监控共用逐集检查：设置电视剧最小值后，单集必须严格大于该值。1GB等于边界也跳过。合集必须取得完整逐集文件信息；只要任一视频文件/单集不超过最小值，整条磁力跳过。缺集号、缺大小或未知合集不再凭平均体积通过。有合格的独立单集或其他合集时，继续按原有补缺集/升级版本规则选择。

软件的普通磁力离线接口不能可靠指定115只下载合集中的部分文件，因此跳过整个不合格合集；不会声称只保存其中的大集。电视剧最大GB仍限制整条资源总大小。最小值留空或0表示不启用逐集最小检查。手动指定离线与115分享转存不使用磁力自动监控的逐集过滤。既有小文件和已接受记录保留，不自动删除云盘文件。

筛选策略版本更新后重置旧扫描断点，防止旧候选直接提交。已接受磁力去重记录保留。

## 合并历史Data

此次按用户要求将工作区各历史交付版本的Data合并到新版EXE同级Data。开发源码ZIP不包含Data、登录凭据和用户日志。

采用最近修改的config.json所在Data作为主配置及主浏览器会话。每套原始Data复制到新版目录的“历史Data备份”，原目录不删除。Data合并报告.json列出来源、主版本、记录统计、解析/文件复制异常，不含凭据值。

合并规则：提交记录按ID去重；115云下载缓存按账户/磁力合并，任务状态优先保留checkedAt较新的结果，重算累计缓存计数；资源数据库合并索引和历史；海报JSON补齐；列表缓存同键使用较新time。现行设置优先，旧版缺失设置补齐。旧版已结束的目录纠正不恢复为待执行队列，避免外部刮削移动后再次被移动。

便携加密字符串先使用各自来源的portable-key.bin解密，再用新版Data对应密钥重新加密。密钥缺失或数据损坏时保留原始备份并报告，不覆盖成伪造的有效登录。浏览器SQLite/LevelDB会话按完整分区选择，不能逐文件混合多个版本的数据库；冲突会话保存在原始备份。登录有效期仍由网站决定，合并Data不能保证网站不再要求验证。

Data及历史备份含个人账户信息，仅放在本机交付目录，请不要将其作为公开开发资料发送给其他人。要让其他AI开发，请提供完整源码ZIP与本文即可。

迁移脚本：tools/merge-history-data.cjs（仅离线文件操作，不运行软件，不请求云盘）。脚本要求新目标尚无Data，防止覆盖已经使用的新版数据。

## 开发与验证

新模块：guangya-provider.js（API协议及目录分页）、guangya-offline.js（持久化提交与去重）、guangya-main.js（官方登录窗口、独立会话和IPC）、guangya-renderer.js（设置方块/离线页）。原有main/preload/三个详情渲染入口及settings导航已接入。

光鸭协议依据官方网页公开代码及作者维护的协议实现，独立实现，未打包第三方驱动代码：

- https://www.guangyapan.com/
- https://github.com/OpenListTeam/OpenList/tree/main/drivers/guangyapan
- https://www.guangyapan.com/static/js/index.2795c2ad.js （本次调查时的官网版本，后续可能变化）

账户：GET https://account.guangyapan.com/v1/user/me；目录：POST https://api.guangyapan.com/userres/v1/file/get_file_list；离线解析：POST /cloudcollection/v1/resolve_res；创建：POST /cloudcollection/v1/create_task。业务响应code=0，创建需data.taskId。请求带官方窗口保存的Bearer令牌。没有调用删除文件/移动文件/删除任务接口。

验证包括30项既有回归、光鸭协议/提交测试、逐集严格边界和候选测试、Data迁移的跨密钥测试，以及Electron真实页面上的设置、目录、批量离线、三站详情和电视剧保存类型。测试均使用模拟会话，不使用真实账户发起离线下载。真实光鸭服务器、账户空间/会员权限及下载完成状态尚需用户登录后验证。

源码包包含package-lock.json、全部电脑版源文件、测试和迁移工具。解压后在cloudsave-windows执行npm ci、npm run dist。交付仍是Windows x64完整便携EXE，程序内app.asar代码与源文件核对，校验报告给出SHA256。
