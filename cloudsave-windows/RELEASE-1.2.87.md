# Windows 1.2.87

## 新增功能
- 离线任务记录增加“待核验至少等待”筛选，可选1小时、6小时、24小时或3天，快速找出提交后长时间仍待下载/目录核验的本地记录。

## 优化
- 选择等待时长会自动切换到“等待115下载/目录核验”，筛选结果与关键词、来源、日期、分页、复制和Excel筛选导出联动；默认“不限”，原有显示不变。
- “清空筛选”、统计快捷筛选及115云下载状态筛选会同步复位等待时长条件，避免隐藏筛选导致记录看起来缺失。

## 修复
- 无效、缺失或未来时间戳不计入等待时长结果；失败状态及115远端任务不会被误认为本地待核验记录。

## 验证
- `npm test`：117/117测试文件通过；UI回归覆盖阈值边界、无效/未来时间、非待核验状态排除、快捷重置与清空筛选。
- 构建目标：Windows x64完整EXE；未更新Docker、飞牛FPK、Android或轻量版本。

## 使用入口
- 打开“离线任务”→“提交记录”，在“待核验至少等待”选择时长。应用后自动筛选待核验记录，可继续按来源、名称或日期缩小范围；使用“复制筛选记录表格”或“导出当前筛选为Excel”处理全部匹配结果。
- 该条件仅按本机提交时间筛选，不触发联网检查、离线提交或转存；选择“不限”或“清空筛选”恢复原显示。
