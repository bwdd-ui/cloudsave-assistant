# Windows 1.2.78

## 新增功能
- 离线任务页增加“状态待确认”筛选，直接查看 115 接口返回了无法识别状态的云下载任务。
- 这类任务明确提示“无法确认是否已保存”，避免被当作正在下载或下载成功；可在管理 → 离线任务 → 提交记录中按此状态筛选并查看详情。

## 优化
- 115 云下载状态摘要显示未知状态数量，状态说明提示该分类不代表保存成功。

## 修复
- 修正云下载任务列表中未知状态不可见、且记录详情缺少保存结果说明的问题。

## 验证与使用
- 隔离数据 Electron UI 冒烟验证：状态计数按钮出现、可筛选出无本地历史的未知状态任务、状态标签和详情提示均正确；现有同步间隔输入校验及设置保持正常。
- 完整 Windows 回归：113/113 个测试文件通过。
