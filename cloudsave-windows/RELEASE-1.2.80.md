# Windows 1.2.80 · 115 完成状态不再冒充目录核验

## 新增功能
- 本版没有新增独立功能入口，重点改进离线任务的状态说明。

## 优化
- 115 状态筛选中的主标签改为“115云下载完成”，并明确使用上次同步的云端状态。
- 完成状态的记录会提示：程序没有核验目标目录内实际文件是否存在，请在 115 中检查目录。

## 修复
- 修复任务仅因 115 下载列表报告完成，就容易被理解为程序已确认文件保存到目标目录的问题。失败、下载中和未知状态也显示相应的 115 任务解释；未知状态仍不代表已保存。

## 使用入口
- 打开“管理 → 离线任务”，查看“115云下载状态与同步”卡片，筛选“已完成”或“状态待确认”。在任务记录中检查顶部的 115 状态、目标目录提示和说明文字。
