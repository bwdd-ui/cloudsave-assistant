# 115两种自动保存独立开关（Windows，2026-10-10）

“离线任务”和“115分享监控”页均增加两个总开关，修改立即保存，两个页面同步显示：

- 自动保存115分享链接：控制115分享监控的定时扫描及转存。任务仍需各自启用，并选择自己的115目标文件夹。来源是对应资源网站可读取到的115分享链接，沿用该网站保存的筛选条件。
- 自动提交磁力到115：控制所有资源网站监控向115提交磁力离线。网站监控本身和自动提交选项也需开启，使用设置中的115默认文件夹。

可只开分享、只开磁力、同时开启或全部关闭。分享开关不改变磁力开关，磁力开关不改变分享任务的启用状态。关闭总开关保留任务、保存目录、断点和历史；重新开启按原任务继续。分享总开关关闭时“立即检查”也停止执行，需先开启总开关。

磁力总开关控制自动监控执行，关闭时各网站自动监控运行暂停；手动点击“添加到115”和批量离线仍可使用。关闭开关后阻止后续提交，已发送到115的请求不能撤回，也不会取消已有下载或转存。

此前功能均保留：115分享去重/提交结果不明时核对再重试、指定保存目录、全部/增量云下载缓存、逐集大小检查、不太灵电影或电视剧保存类型、光鸭手动/批量离线。此处总开关只针对115，光鸭与123监控不受影响。

分享转存不是磁力离线下载，不纳入115云下载状态统计。成功标记分享后不会再检查该分享内部后续新增的文件。网盘自身需要登录，资源网站也需要能读取到分享链接。

## 实现

Data/config.json保存automation115：share与magnet两个独立布尔值。未配置时沿用已有行为（两个总开关默认允许），但不会自动启用此前未开启的网站监控或分享任务。新入口automation115-renderer.js与preload的automation115 IPC交互，分别显示两个页面的同步控件。

share115-monitor.js增加enabled依赖，在安排定时器、启动扫描和扫描过程检查总开关。关闭时停止当前扫描并清除定时请求；恢复后重新安排已启用任务。四个GuanyingMonitor复用站点增加magnetEnabled依赖，不修改保存的站点选项。不太灵运行入口检查总开关，115统一提交入口在开始及发送POST前再次检查自动来源，避免排队期间关闭后仍提交。

测试覆盖四种开关组合、页面同步、分享定时器暂停/恢复、任务启用状态保留、自动来源不访问云盘/不提交、手动来源仍使用正确目录；原有30项回归通过。本次没有用真实账户提交云盘请求。

EXE仍为Windows x64完整便携版，打包后核对实际EXE中的app.asar与源文件。源码ZIP含全部电脑版源码、依赖锁、测试及开发说明，不含个人Data。历史Data按已有规则继续合并，个人备份位于本机新版目录；复制异常见Data合并报告.json。旧版占用的Cookies无法读取时仍需退出旧版才能补齐，不会伪称完整迁移。
