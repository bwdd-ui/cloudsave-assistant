# Windows 1.2.82 · 七味验证页识别

## 新增功能
- 本版没有新增独立功能入口。

## 优化
- 七味资源读取遇到 HTTP 403 时也检查响应正文，识别中英文安全验证页，并将验证窗口定位到刚才访问的搜索或影片页面。
- 增加对常见人机验证和浏览器挑战标记的识别。验证页不会被保存为有效的空搜索缓存。

## 修复
- 修复部分七味验证挑战以 HTTP 403 返回时仅显示普通读取错误、用户误以为影片搜索无结果的问题。完成网站验证后会自动重新读取当前搜索页。

## 使用入口
- 打开“资源库七味”并搜索；若站点要求验证，按提示点击“网站验证”，完成页面验证并关闭验证窗口，软件会重试当前搜索。

## 验证
- 新增隔离网络回归覆盖：403 人机验证、保留验证 URL、挑战页不写缓存及普通 403 错误语义。
- 七味停止和监控回归通过；`npm test`：114/114 测试文件通过。
- 未访问真实网盘账号，未触发离线或转存。
