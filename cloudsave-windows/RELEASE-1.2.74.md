# Windows 1.2.74

## 新增功能
- “运行日志”新增关键词、资源网站和级别组合筛选，便于从近期记录中定位资源保存失败、验证拦截或任务进度。
- 增加清除关键词按钮；筛选条件只影响当前内存显示，不修改或删除日志。

## 优化
- 界面显示当前筛选命中数；刷新日志后保留筛选条件。
- 明确提示搜索范围是内存中的最近500条；“下载日志”仍导出当天完整日志，不受筛选影响。

## 修复
- 增加直接定位近期问题日志的工具，减少在不同网站与任务记录中逐条查找。

## 验证与使用
- 入口：左侧“管理 → 运行日志”，组合选择资源网站、级别并输入关键词；使用“清除关键词”快速恢复。
- 测试：关键词命中消息/详情、网站与级别组合、清除操作、无匹配状态及完整自动化回归、隔离数据桌面冒烟测试。
- 本次仅构建 Windows x64 完整便携版，不包含用户 Data 或私人日志。
