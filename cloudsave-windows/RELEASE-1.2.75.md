# Windows 1.2.75

## 新增功能
- 115下载完成但原输出文件已移动或删除时，提交历史新增“下载完成，位置未核实”状态，并可在状态筛选和“需要关注”中单独定位。
- 历史中已确认存入目标文件夹、仅被115接受等待下载、以及下载完成但位置未核实，分别显示不同状态。

## 优化
- 批量提交计数和导出表格采用更准确的“已提交/待核对”及“已加入离线任务，等待完成”表述，避免把受理当作下载与落盘完成。
- 升级后会依据本地已保存的目录核对结果，将旧版中“原输出不可用”但记录为成功的条目修正为“位置未核实”。

## 修复
- 修复115任务报告完成、但文件ID已不存在时仍记为保存成功的问题。该情况现以警告记录，并保留资源去重状态，避免自动重复提交。

## 验证与使用
- 入口：左侧“管理 → 离线任务 → 提交记录”，按“下载完成，位置未核实”或“需要关注”筛选；运行日志会显示警告。
- 测试：完成任务无输出文件、旧记录迁移、去重保护、状态筛选/导出、桌面隔离数据冒烟和完整回归测试。
- 本次仅构建 Windows x64 完整便携 EXE；不包含 Data、账号信息或私人日志。
