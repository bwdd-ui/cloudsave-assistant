# Windows 1.2.73

## 新增功能
- 在“离线任务 → 提交记录”分页栏增加“复制本页记录”，可将当前可见页复制为表格并粘贴到 Excel/WPS。
- 原有“复制筛选记录表格”仍复制所有筛选匹配页；新按钮只复制当前页，不改变筛选、分页或记录。

## 优化
- 复制本页按钮显示当前页记录数；没有匹配记录时自动禁用。
- 复用现有表格转义和公式安全处理逻辑。

## 修复
- 增加分页栏的当前页快速复制入口，避免用户为复制小段记录而复制全部筛选结果。

## 验证与使用
- 入口：左侧“离线任务” → “提交记录”，应用需要的筛选并翻到目标页，点击“复制本页记录（数量）”。
- 回归测试：验证第一页/第二页仅复制对应行、按钮空结果状态和现有筛选导出行为；完整自动化测试及 Windows x64 桌面冒烟检查通过后发布。
- 此版本只更新 Windows x64 完整便携版。
