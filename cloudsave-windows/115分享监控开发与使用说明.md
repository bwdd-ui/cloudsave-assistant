# 115分享监控（Windows，2026-10-09）

本次新增独立“115分享监控”，用于扫描资源网站上可读取的115分享链接，转存到每个任务指定的115文件夹。它与原有磁力离线下载、115云下载同步、123分享监控互相独立。

## 使用

1. 在设置中通过115登录窗口或Cookie登录115。需要登录的资源网站也先完成登录/验证。
2. 在相应网站的自动监控页面保存筛选和分类，不必开启磁力自动提交。
3. 左侧进入“115分享监控”，填写任务名称，选择网站、检查间隔、每轮页数和每轮分享上限。
4. “选择文件夹”逐层打开115目录，点击“使用当前文件夹”；明确选择根目录也允许。系统不会在目录失效时自动改用根目录。
5. 保存任务，点击“立即检查”试运行；勾选“开启自动监控”后定时检查。可新建多个独立任务，每个任务一个网站和一个目标文件夹。
6. 扫描期间可停止。当前已发出的网络请求需要返回后才能结束；停止不会撤销115已接受的转存。

## 范围与行为

- 五个现有网站适配器可用于扫描；只有适配器能读取到的115分享才会转存。当前BT影视适配器仅解析磁力/种子，未识别网盘分享，因此BT影视任务可能没有可转存链接。不会把其他网盘链接当成115。
- 支持115.com、115cdn.com、anxia.com和share.115.com的标准分享地址。提取码从链接password/receive_code参数、四位片段或网站已有提取码字段读取。
- 沿用所选网站自动监控已保存的分类、年份、类型、更新时间、电影/剧集大小范围等条件。每轮重新取得筛选快照；修改筛选后扫描断点重置。分享大小缺失时尝试汇总分享顶层文件大小，目录没有准确大小时不能保证适用大小筛选。
- 每轮刷新各分类首页，同时用断点逐步访问后续页面；默认每轮3页、最多20个新分享。当分类多于每轮页数时轮换首页，避免只访问第一个分类。达到上限后下轮继续，不承诺一次扫描全站。
- 分享顶层文件和目录整体转存；目录由115转存接口处理其内部树。成功标记后跳过整个分享，不检查同一分享后续新增的文件。这是资源网站新分享监控，不是分享内部文件的增量追踪。
- 去重身份包含115账户、目标目录、分享码、文件ID。换目标目录可以再次保存；更换115账户后原账户任务不会执行，需重新配置任务。
- 状态“115已接受转存”表示接口明确接受请求，并不表示程序已在目标目录逐文件核验。分享过期、提取码错误、网站验证、115登录失效、空间或权限限制会留下错误记录。
- 结果不明、超时、程序在提交过程中关闭等情况，会保留“准备中/结果未确认”记录，后续不会自动再次提交。用户核对目标目录后，可标记已转存，或允许重试。明确拒绝的请求可在后续轮次重试。
- 分享转存不是云下载任务，不会计入离线任务的“下载中/失败/完成”，也不会因此触发磁力提交后的云下载同步。
- 定时任务要求Windows程序保持运行；关闭到托盘可以继续，退出程序或系统休眠期间不执行，重新启动后恢复已启用任务。

## 结构与持久化

- `share115-provider.js`：标准分享地址解析、完整分页读取、单次转存调用。只使用share/snap和share/receive，没有删除和移动接口。
- `share115-monitor.js`：任务定时器、扫描断点、账户/目录验证、逐文件去重、提交前意图写盘、明确/不明结果、人工核对处理。
- `share115-renderer.js`：任务编辑器、115目录浏览、运行/停止、独立转存记录。
- `main.js`：站点适配和六个share115 IPC；使用已有115会话、目录验证和缓存写盘逻辑。
- `preload.js`：share115State/Save/Remove/Run/Stop/Resolve及状态事件；`navigation-settings.js`将入口纳入监控分组。
- 通过现有缓存路径保存`share115-monitor.json`，其中version、tasks、items、transactions、shares、shareFiles分别保存版本、任务、逐文件状态、操作记录、已接受分享及其文件集合。请保留原有Data及会话目录，不要删除分享记录，否则无法继续去重。
- 每次转存前持久化intent，再执行一次POST；每批最多50个顶层项目。完整分页检查总数和ID，重复分页或扫描期间内容变化均不提交。部分批次接受、部分结果不明时，不标记整个分享已接受。
- 状态写盘使用现有本地缓存和jsonStore.flush；程序退出等待正在运行任务结束。损坏数据文件会报初始化异常，不默默覆盖原文件。

## 协议出处

- 115官方分享转存说明：https://q.115.com/115115/T479428.html
- p115client作者维护的协议实现：https://github.com/ChenyangGao/p115client
- GET `https://webapi.115.com/share/snap`：share_code、receive_code、cid=0、limit=100、offset；读取data.list/data.count。
- POST `https://webapi.115.com/share/receive`：share_code、receive_code、file_id（逗号分隔）、cid（用户指定目标目录）。使用已有115 Cookie会话。
