# 多网盘共用筛选版（Windows全量版）

## 使用方法

进入不太灵、观影、BT影视、聚影、七味各自的“自动监控”页面，即可同时看到磁力自动离线开关、115分享监控开关、原有磁力筛选与分享筛选/任务表单，不再点击额外入口进入。资源库页面不再显示这两项开关。两项独立控制；磁力仍使用对应网站已保存的监控条件。

一个分享任务对应一个115保存文件夹，可创建多个任务。任务自身需要开启，网站分享开关也需要开启。保存任务前须登录115并选择有效目录。正在扫描也可以保存任务和设置：立即写入本地，当前轮保持开始时的目录与条件，新设置下轮生效；保存时关闭正在运行的任务，会停止后续处理，不撤销已经接受的转存。

左侧“网盘保存日志”，集中显示各网站任务日志和最近转存记录，可选择全部网站、指定网站及任务，实时更新并支持导出。筛选/任务表单与日志为同级导航，无需从分享表单进入日志。切换网站保留各自未保存的表单草稿；退出软件前仍须点击保存任务持久化。

分享任务独立设置：

- 最近多少天：0表示不限；日期优先采用网站提供的绝对或相对时间。
- 资源最小/最大GB：留空或0表示该边界不限；网站未提供大小时，按完整分享文件树合计大小。
- 每轮扫描方式：按识别到的115链接数，或按检查的电影/电视剧条目数。链接计数包括重复、被筛选跳过的115链接，避免无限扫描；影片计数包括读取失败及未提供链接的条目。
- 每轮扫描数量：限制扫描工作量。已取消本轮保存数量上限，本轮扫描范围内所有符合条件的分享均可保存，旧任务的maxShares数值也不再限制。
- 检查间隔：单位分钟。网站分页自动处理，不再需要填写每轮页数。

启用日期或大小条件时，无法确认对应信息的分享会跳过并记录原因，不会假定符合条件。网站自身的磁力年份、题材、画质和排序条件不再混入分享任务。

## 视频格式筛选

“必须包含的格式”和“出现即跳过的格式”填写文件扩展名，用逗号、空格或中文逗号分隔，大小写不限，例如 `MKV, MP4`。两项留空时不进行格式筛选。

必须包含：默认只要包含填写格式中的任意一种即可；勾选“必须全部包含”后，填写的每一种格式都必须出现。例如填写MKV、MP4，分享只有MKV时，默认通过；勾选全部包含则跳过。

出现即跳过：例如填写AVI，只要整个分享（包括子文件夹）出现一个AVI文件，就跳过整条分享。该条件优先于必须包含条件。例如分享同时有MKV和AVI，要求MKV、排除AVI时仍然跳过。

格式按文件名扩展名判断，不会分析视频内容、编码、分辨率或HDR。不修改分享内文件，不只转存符合格式的一部分。格式筛选通过后，按分享顶层目录/文件整体转存到指定目录。若文件名称缺失、目录分页不完整、读取失败或目录层级超过20层/文件节点超过100000个，无法确认格式时不执行转存，日志记录原因。开启格式和大小条件时共用已读文件树，减少重复请求。

已成功接受转存的分享按115账户、目标目录和分享ID去重。修改格式条件不会重新保存之前已接受的同一分享，也不会删除云盘里的旧文件。

## 自定义网站

左侧“自定义网站115监控”支持输入完整HTTP/HTTPS地址，不能在URL中包含账号密码。程序读取公开静态HTML，尝试识别115.com、115cdn.com、anxia.com等支持的115分享链接、提取码、附近日期与大小，以及同站影片详情和下一页。

这不是通用网站适配保证。需要登录、验证码、动态JS加载或特殊布局的网站，可能无法自动提取；程序不会把115或其他站点的登录凭据发送给自定义网站，只继续读取输入地址所属站点的详情和分页。登录失败、缺失元数据或无法识别内容时应查看日志。复杂网站需要新增专用适配器。

## 进度、记录与日志

扫描在数量上限处保存分类页码、影片位置和影片内链接位置，下一轮继续。分类全部扫描完后从头开始新周期。大型片库尚未扫完时会继续后续页，首页新增内容将在下一周期检查；并非每轮重新扫描全库。内部还保留分页/影片安全上限以防异常网站无限返回。

左侧网盘保存日志实时显示扫描、跳过原因、目录与结果；按网站和任务筛选或导出日志。运行日志中的115分享监控分类也记录过程。页面保留最近500条分享日志及最近100条转存记录。

每次转存先持久化意图，再调用115接口。请求结果不确定时不会自动重复，需核对目标目录后标记已转存或允许重试。“115已接受”表示接口接受请求，不等于软件已逐文件核对云盘内容。每次请求携带所选目录CID，不退回根目录。

## 更新和Data

这是完整Electron电脑版，保持全量运行环境，不依赖另装浏览器运行时。最小化仍为正常最小化，关闭主窗口默认后台运行；本次不改变该行为。更新前退出旧客户端，再运行新交付目录内EXE，避免浏览器会话数据库被占用。

交付目录的Data由历史版本合并；原始历史Data保留，目录下“历史Data备份”保留原始副本，“Data合并报告.json”记录来源及失败项。若报告出现EBUSY，表示对应文件仍被占用，尤其Cookies不能保证完整复制；不要把报告有警告理解为全部登录会话已迁移。Data包含私人账户和历史记录，不应公开上传。

源码ZIP不含Data、账户密钥、实际运行日志、node_modules和dist；用户Data单独保存在交付目录。此版本修改范围为Windows，Android和飞牛安装包未重新发布。

解压源码ZIP后，使用package-lock.json执行 `npm ci`，`npm start`运行开发客户端；`npm run dist`构建Windows portable EXE。具体Electron/构建工具版本以锁文件为准。项目原有开发资料、工具与测试均随源码提供。应用ID、菜单、协议、账户/session缓存逻辑维持当前源码配置。

## 已扫描缓存和增量检查

scannedLinks记录完成检查的115分享。缓存隔离115账号、目标目录、分享ID、提取码及日期/大小/格式筛选条件。下次遇到已扫描链接，直接跳过115文件清单请求；修改扫描数量不使该缓存失效。修改筛选条件、提取码或保存目录可重新检查。已转存的分享无论新筛选如何均优先去重，避免重复保存。网络读取失败/转存失败不记为完成检查，后续仍可重试；结果不确定保持待核对，用户核对后允许重试会清除相应扫描缓存。

已完成检查后跳过意味着同一分享链接内后续增加文件不会再次自动检查。该模块是资源网站链接转存监控，不是对每条分享内容持续比对的同步任务。

## 光鸭磁力与分享转存（本次新增）

各网站“自动监控”中使用同一套网盘保存表单，选择“保存网盘：光鸭云盘”，再分别勾选“光鸭磁力离线”和“网盘分享链接转存”。两项可单独开启或同时开启，共用本任务的最近天数、资源大小、格式、扫描数量和检查间隔。选择115时保持115分享转存功能。可以新建多个任务，为不同网盘、目录或条件分别保存；任务彼此独立，不会随保存网盘切换而把旧任务重定向。

先在设置 → 光鸭云盘打开官网登录，然后在任务表单选择光鸭目录。每个任务保留自己的目录，不改变手动/批量光鸭离线默认目录。切换保存网盘会清空当前表单所选目录，必须重新选择；不使用115目录ID冒充光鸭目录ID。上方“启用本站网盘保存任务”为该站115/光鸭任务共同的总开关。上方“启用本站115磁力自动离线”控制原有115磁力监控；光鸭磁力由下方光鸭任务内的磁力选项控制。

光鸭任务读取该资源网站的光鸭分享链接和磁力/ed2k资源，按同一套条件筛选。分享读取顶层清单和子目录；磁力使用光鸭resolve_res的btResInfo递归清单，转存/离线携带明确parentId。日期依据资源站标注，大小缺失时读取实际文件信息，格式按所有叶子文件扩展名检查。磁力文件清单数量/索引不完整时，不按平均大小或猜测索引放行。启用全局电视剧单集大小限制时，光鸭电视剧磁力也检查实际视频文件大小，不符合时整条拒绝。

数量不限保存，仍按本轮扫描范围处理。保存成功/检查完成缓存按目标网盘、账号、目录和资源隔离。115和光鸭相同账号数字或资源标题不会混用去重记录。“网盘保存日志”集中显示网站、任务、保存网盘、操作类型及任务回执ID。收到taskId表示云盘已接受任务，不表示下载完成；没有明确回执的请求保留为待核对，可在日志页核对后允许重试。此模块没有假定光鸭任务已下载完成，也没有实现光鸭云下载状态同步。

本次官网接口依据公开网页JS及匿名只读分享列表验证：

- https://www.guangyapan.com/ 和其分享页面 /s/<shareId>；提取码参数code。
- https://www.guangyapan.com/static/js/index.2795c2ad.js（2026-10-11公开版本）。
- /userres/v1/get_share_access_token：shareId、code，返回data.accessToken。
- /userres/v1/get_share_page_files_list：accessToken、parentId、pageSize、数字cursor、orderBy、sortType；校验total/list/cursor。
- /userres/v1/restore_share：accessToken、fileIds、parentId，明确返回data.taskId。
- /cloudcollection/v1/resolve_res、/cloudcollection/v1/create_task：沿用已有光鸭离线接口；递归选择所有有效叶子fileIndex。

兼容code=0及msg=success且省略code的明确成功响应，写请求同时要求任务回执。API可能随官网更新，异常时停止该条并写日志。登录令牌及分享访问令牌只保留在现有加密账户配置/运行时内存，不放入日志或源码包。

新增guangya-share-provider.js复用完整分页/文件树检查，guangya-main.js向统一调度暴露光鸭传输后端，share115-monitor.js兼容旧115任务并保存destination/magnetEnabled/shareEnabled字段，main.js向调度返回磁力和分享资源，custom-share115-provider.js识别公开静态HTML中的光鸭/磁力链接。磁力开启时读取完整详情，不只取摘要或仅有网盘的目录。
