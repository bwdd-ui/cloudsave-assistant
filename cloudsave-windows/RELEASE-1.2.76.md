# Windows 1.2.76

## 新增功能
- 无新增用户操作入口；保持现有提交记录、状态筛选与保存行为。

## 优化
- 提交记录摘要计数改为单次遍历历史列表，同时计算总数、已提交/待核对、自动跳过和需要关注数量，避免大历史列表每次重绘都重复扫描。

## 修复
- 保持 v1.2.75 的保存状态核对：115报告任务完成但输出文件不可查时显示“下载完成，位置未核实”，不再误报已保存到目录。

## 验证与使用
- 使用入口不变：左侧“管理 → 离线任务 → 提交记录”；摘要数字与对应状态筛选保持一致。
- 回归覆盖所有摘要状态与筛选规则，并包含完整回归及隔离数据桌面冒烟测试。
- 本次仅构建 Windows x64 完整便携 EXE；不包含 Data、账号信息或私人日志。
