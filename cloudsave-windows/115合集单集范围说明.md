# 115合集单集大小范围（电脑版，2026-10-10）

离线任务顶部新增“115电视剧单集大小”：勾选“提交115前检查”，设置单集最小GB和最大GB，再点击“保存单集设置”。留空或0表示该边界不限；两个边界都不限时不检查大小。保存后对新提交立即生效。此次本机交付的Data按用户要求启用最小1GB、最大不限。

判定是整条合集通过或整条跳过：单集必须严格大于最小值且不超过最大值。比如最小1GB、最大3GB：500MB、1GB、3.1GB均不合格，3GB合格。合集里任意单集不合格，整条磁力不提交115。缺少集号、逐集大小、完整文件清单时也不提交，不用“合集总大小÷集数”的平均值代替。

设置在115统一提交入口检查，覆盖资源详情手动提交、批量离线，以及所有资源网站自动监控。与网站监控筛选同时生效，两个范围都需要通过。只影响新提交；此前已经接受的任务和云盘文件不删除、不重新下载。

115依然使用设置中的指定保存文件夹，提交请求明确携带wp_path_id。文件夹失效、账户变更时停止，不回退根目录。不支持可靠选择磁力合集内部的部分集数，所以采用整条跳过，不会先提交再删除小单集。

批量离线新增“资源类型”：自动识别、电影、电视剧/合集。纯磁力不包含文件清单，自动识别只使用可信的已缓存元数据或可识别的资源名称。开启大小检查时，未知类型不能绕过检查；请选择相应类型。选择电视剧且未缓存完整清单时会跳过。软件可从对应资源网站补查已知影片的种子清单，但不能保证任何裸磁力都能预先取得文件列表。电影不使用单集规则。

本次保留光鸭离线与115分享监控功能；单集设置只应用于115磁力离线，不应用于光鸭或115分享转存。此前不太灵“只保存电影/只保存电视剧”选项及网站自身筛选仍保留。

新增tests/test-offline-episode-size.cjs验证最小值等于边界、最大值边界、混合大小合集、缺清单、未知批量类型、提交请求前拦截，以及合格合集仍使用指定115目录；新增Electron页面测试验证默认1GB、开关和范围保存、电视剧批量类型传递。原有30项回归通过。
