# Windows 1.2.86

## 新增功能
- 离线任务提交记录新增时间排序：可按默认记录顺序、等待最久优先或最近提交优先查看；适合配合“等待115下载/目录核验”状态快速定位等待较久的记录。

## 优化
- 排序设置保存在本机，下次打开仍沿用；默认继续采用原有新记录在上的顺序。排序作用于当前筛选结果，也会一致地用于分页、复制及筛选导出。

## 修复
- 无效或缺失时间戳始终排在有有效时间的记录之后；相同时间保留原记录顺序，避免排序时记录跳动或丢失。

## 验证
- `npm test`：117/117 测试文件通过；UI 回归覆盖默认顺序不变、最早/最近排序、无效时间位置和本地偏好保存。
- 构建目标：Windows x64 完整 EXE。未更新 Docker、飞牛 FPK、Android 或轻量版本。

## 使用入口
- 打开“离线任务”→“提交记录”，可在“时间排序”下拉框选择“等待最久优先（最早提交）”或“最近提交优先”；需要时可同时选择“等待115下载/目录核验”状态。
- 排序只调整本机记录显示和导出顺序，不联网、不发起离线或转存操作。
