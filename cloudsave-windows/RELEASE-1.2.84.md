# Windows 1.2.84

## 新增功能
- 自动监控页的待核验数量现在带有快捷入口。点击“查看 N 条待核验记录”会直接打开离线任务提交记录，并筛选 115 等待下载完成/目录核验状态。

## 优化
- 快捷入口会清除旧的来源、关键词和日期条件，避免旧筛选组合导致记录被隐藏；提交记录中增加独立的“等待115下载/目录核验”状态选项。

## 修复
- 修正从监控页查看待核验数量后，仍需手动切换页面并逐项调整筛选才能找到对应任务的问题。

## 验证
- `npm test`：116/116 测试文件通过；新增导航回归覆盖待核验计数显示/隐藏、筛选重置和页面跳转。
- 构建目标：Windows x64 完整 EXE。未更新 Docker、飞牛 FPK、Android 或轻量版本。

## 使用入口
- 打开“自动监控不太灵磁力链接”页面；存在待核验任务时点击状态区下方的“查看 N 条待核验记录”。
- 该入口只读取现有本地提交记录并设置筛选，不会发起离线、转存或其他外部写操作。
