# Windows 1.2.77

## 新增功能
- 七味资源详情分类支持依据明确的标题/分组标注识别光鸭云盘（含“黄鸭云盘”称呼）；短链或通用分享域名不再一律落入“其他云盘”。

## 优化
- 提交记录摘要（总数、已提交/待核对、自动跳过、需要关注）改为同一次列表遍历中统计；历史规模较大时不再为各摘要分别重复扫描。
- 当链接域名能识别网盘时，优先以域名分类，避免与标题文字冲突造成误分类。

## 修复
- 延续 v1.2.75 的离线保存状态修正：下载任务完成但原输出文件不可查询时，显示“下载完成，位置未核实”，不将其误认为已保存到目录。

## 验证与使用
- 使用入口：资源库 → 七味 → 打开影片详情查看“其他网盘链接”分类；离线提交记录摘要显示入口仍为管理 → 离线任务 → 提交记录。
- 回归覆盖标题别名、未知分享域名、可识别域名优先级、历史状态计数和单次遍历；运行完整回归及隔离数据桌面冒烟。
- 本次仅构建 Windows x64 完整便携 EXE；不包含 Data、账号信息或私人日志。
