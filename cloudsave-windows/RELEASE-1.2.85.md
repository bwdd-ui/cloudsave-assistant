# Windows 1.2.85

## 新增功能
- 离线任务记录中，仍在等待115下载完成或保存目录核验的记录会显示提交后已等待的时长，方便优先发现长时间未完成的任务。

## 优化
- 等待时长使用本地提交记录时间，以分钟、小时或天显示；无效或未来时间戳不显示时长，并明确提示这不是115实时下载进度。

## 修复
- 修正历史记录只显示等待状态、无法快速判断哪些记录等待时间较长的问题。

## 验证
- `npm test`：新增等待时长边界回归，覆盖分钟/小时/天、无效及未来时间戳，并确认仅待完成记录显示。
- 构建目标：Windows x64 完整 EXE；不更新 Docker、飞牛 FPK、Android 或轻量版本。

## 使用入口
- 打开“离线任务”提交记录；状态为“已加入离线任务，等待完成”的记录显示“已等待 X”。从监控页进入待核验记录筛选也会显示该信息。
- 时长只依据本机保存的提交时间，不会联网检查或自动发起离线、转存操作。
