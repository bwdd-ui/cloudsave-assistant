# Windows 1.2.79 · 115 下载结果以云端状态为准

## 新增功能
- 在 115 云下载状态筛选结果里，已有本地提交记录也会以 115 的实际任务状态显示主状态标签。选择“已完成”时显示“下载成功”，不再混用本地“已提交/待核对”状态。

## 优化
- 未识别的 115 任务状态继续明确标记为“状态待确认”，并提示这不代表已保存。

## 修复
- 修复本地提交记录与 115 云下载列表合并后，主状态仍显示旧本地状态、与云端下载状态相互矛盾的问题。没有本地提交记录的 115 云任务显示逻辑不变。

## 使用入口
- 打开“管理 → 离线任务”，在“115 云下载状态与同步”卡片选择“已完成 / 下载失败 / 正在下载 / 状态待确认”筛选；检查每条记录顶部主状态及下方的 115 云下载说明。筛选所有提交记录仍显示本地提交状态。
