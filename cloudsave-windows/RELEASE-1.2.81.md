# Windows 1.2.81 · 明确115已接受与实际落盘状态

## 新增功能
- 本版没有新增独立功能入口。

## 优化
- 监控页及扫描完成提示把“115已接受提交”明确标为待下载完成和目标目录核验，降低把提交任务误认为文件已保存的可能。

## 修复
- 修复监控中间状态将已接受任务显示为“已自动提交、目标目录”的歧义。
- 扫描结束时提醒用户：提交成功不代表已下载到目标目录，并指引到“离线任务”核对下载状态与实际保存目录。

## 使用入口
- 打开“监控筛选”，运行或等待一次扫描；检查扫描中的状态以及完成提示。
- 打开“管理 → 离线任务”，核对115云端下载状态和实际文件所在目录。监控提交接受只代表任务已被115接受。
