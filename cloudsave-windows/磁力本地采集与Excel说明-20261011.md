# 磁力本地采集与Excel版（Windows全量）

本次包含新建网盘任务按钮修复、光鸭/115共用筛选功能，并新增五个网站的仅扫描磁力功能。

## 使用

进入任一网站的“自动监控”，勾选“仅扫描磁力并保存到本地，不提交离线”，然后设置该站原生筛选：电影/电视剧分类、年份、类型、地区、画质、大小、最近天数/分钟或指定日期等。点击“立即检查”采集；点击“导出采集磁力Excel”保存xlsx。需要定时采集时开启该站自动监控并设置原有检查间隔。

这个模式只收集磁力链接文字及资源资料，不下载影视文件，不提交115或光鸭离线，也不转存分享。无需登录网盘或选择云盘目录；资源站本身要求登录/验证时，仍需在设置中登录相应网站。仅采集模式暂停同一网站的网盘保存任务；其他网站的独立任务不在这个开关控制范围内。退出仅采集模式后，自动提交须另外明确开启。

采集使用当前筛选范围，保留全部符合条件的不同版本及以前已提交过的磁力，按磁力哈希在本次结果去重。不按“最大版本”、离线历史或“本次提交数量”删减。电影/电视剧资源大小以网站资源记录筛选；不会执行保存阶段的逐集覆盖、已下载比较等提交选择。

分页按官网筛选读取，不退回无筛选全库。遇到分页重复、年份筛选异常、登录验证或网络错误，沿用原有停止/退避机制。中断保留扫描断点及已采集结果，可以先导出已完成部分，再继续检查。更改筛选会启动该条件的新结果集；完成后一轮按原条件重新检查最新更新，结果集是当前筛选扫描快照，不是永远累加不同筛选范围的历史全集。

结果保存在现有Data内的各站扫描导出缓存：不太灵scan-export.json（实际文件名以源码常量为准）、观影guanying-scan-export.json、BT影视btbtla-scan-export.json、聚影jying-scan-export.json、七味qmp4-scan-export.json。按磁力去重，扫描未完成时也持久写入。软件关闭后仍可使用本地结果导出。

## 全部Excel统一格式

不太灵/观影/BT影视/聚影/七味扫描导出及离线任务历史导出，共用以下列：

1. 名称：对应海报影片/剧集的中文名称。
2. 资源大小：整条磁力/种子的总大小，保留GB/MB等单位；未知留空。
3. 上映时间：影片或剧集上映日期，不是磁力发布时间。
4. 磁力链接。
5. 磁力名称：网站提供的磁力/种子名称，缺失时使用媒体文件名。
6. 时长。
7. 分辨率。
8. 帧率。
9. 视频。
10. 音频。
11. 类型。
12. 制片国家/地区。

已移除磁力发布时间、提交时间、来源、状态、保存目录、反馈。发布时间仍可在内部缓存中用于筛选，但不写入Excel。名称来自网站海报/影片详情，本程序不自行翻译或臆造中文名；旧历史优先从本地影片资料补全，网站或缓存缺失的字段留空。MediaInfo类字段只有源站提供/读取到时才填写，不会从文件名猜测真实编码、帧率或时长。导出仍使用已有媒体补全流程，读取额外资料可能比只采集链接慢。

## 新建任务修复

点击“＋新建任务”会显示新建状态、建议名称并聚焦名称输入框。网盘、目录和筛选保留，点击“创建任务”才保存。编辑已有任务时显示“保存修改”；从编辑状态新建不会覆盖旧任务。新任务默认不启用自动运行。创建完成后保留参数，便于连续创建多个任务。

## 文件和复现

请退出旧程序及其托盘实例，再运行同一交付文件夹里的“云存助手-Excel列顺序版.exe”。沿用该目录现有Data，本次不再次复制Cookie数据库，不修改云盘账户记录或清空历史。旧EXE和原源码包保留。原先Data合并报告中的被占用文件警告不会因本次界面和导出更新自动补齐。

最新源码包为“完整源码与Excel列顺序开发资料.zip”，不含私人Data/账户密钥/node_modules/dist。npm ci安装锁文件依赖，npm start开发，npm run dist构建完整Electron电脑版；package.json包含新增scan-only-renderer.js。

实现位置：guanying-monitor.js的scanOnly选项负责四站本地扫描；main.js的monitor.scanOnly负责不太灵扫描。scanOnly在后端强制autoSubmit=false并绕过云盘登录/目录依赖，同时跳过提交候选、历史去重和覆盖选择，保留实际筛选后的磁力。libraryScanOnly/libraryShareEnabled暂停该站分享保存；scan-only-renderer.js在各自动监控页暴露独立选项并禁用自动提交控件。原生筛选仍由各站renderer和provider处理。scan-export.js统一中文名称首列及标准表格结构，main.js历史导出不再追加提交字段。

验证：原有30组回归通过；test-scan-only-mode.cjs使用不太灵实际扫描代码及四站通用扫描器，断言云盘登录、目录、同步、提交、覆盖调用为零，即使离线总开关关闭/无网盘Cookie/提交数量为1，仍保留全部匹配资源；test-scan-only-ui.cjs验证五站模式和提交控件；test-excel-resource-name.cjs及生成xlsx的ZIP/XML检查验证中文名称首列和删除指定列；test-new-cloud-task-ui.cjs验证创建多个任务不覆盖旧任务。没有对真实云盘执行写操作。
